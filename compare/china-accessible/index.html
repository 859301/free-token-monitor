未标注国内直连的额度怎么办

国内直连情况未确认的 25 条以海外厂商为主（Gemini、Groq、OpenRouter、Cloudflare、Deepgram、Tavily 等）。它们的可用性说法不一：以 OpenRouter 为例，有来源称「不受墙限制」，也有来源称「大陆访问需要代理」。两种说法都存在，无法裁决。

判断方法：直接打开厂商网站测试，或用一次 curl 调用测试 API 端点是否通；网站能打开不等于 API 能调用，支付环节也可能单独受限。实测时注意：不要用多账号、绕过地区规则等违反厂商条款的方法。
