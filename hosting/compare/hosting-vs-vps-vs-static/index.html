虚拟主机 vs VPS vs 静态托管

核实于 2026-11-13 · 本页更新于 2026-11-13

三类服务能力不同：虚拟主机给一块能跑 PHP、连 MySQL 的空间，可装 WordPress，免运维；VPS 给一台有 root 权限的服务器（以 EUserv VS2-free 为例：IPv6-only、每月手动续期），环境自己装；静态托管只发 HTML/CSS/JS，没有 PHP 与 MySQL，WordPress 跑不了。Discourse 与 Node 应用需要自有运行环境，PHP 虚拟主机跑不了。

虚拟主机

虚拟主机给一块能跑 PHP、连 MySQL 的空间，带面板与一键安装器，可装 WordPress、博客与企业站，免运维。限制写在各家官网：空间、流量/hits、数据库数量、PHP 版本、闲置与删站规则。本列表的 10 家都是虚拟主机。

VPS：以 EUserv 为例

EUserv VS2-free 是容器型 vServer，带完整 root 权限：1 核 @ 1 GHz、1 GB 内存、10 GB 硬盘、每月 1 TB 流量。基础版免费 IPv4 地址为无，免费 IPv6 地址 1 个 /128；合同期 1 个月，续期方式为手动。VPS 没有 PHP/MySQL 面板托管语义，环境、数据库、安全都自己装自己管。详情见 EUserv 详情页。免费 VPS 的另外形态（甲骨文 Always Free、GCP e2-micro 等）见免费 VPS 列表。

静态托管

静态托管只发布 HTML、CSS、JavaScript 等静态文件，没有服务器端 PHP 与 MySQL，WordPress 跑不了，动态程序跑不了。GitHub Pages、Netlify、Cloudflare Pages 属于这一类。静态托管不在本列表的核实范围内，这里只作能力边界区分。

常见问题

Discourse 论坛能在免费虚拟主机上跑吗？

跑不了。Discourse 需要自有运行环境（Ruby、PostgreSQL、Redis 等），PHP 虚拟主机没有。论坛里有用户问同样的问题，回复是“InfinityFree 是 php 虚拟主机，跑不了”（用户说法）。需要跑 Discourse 的可选 VPS，自装环境。

WordPress 应该选哪类服务？

WordPress 需要 PHP + MySQL：虚拟主机可直接装（一键安装器），VPS 可自装环境，静态托管跑不了。虚拟主机免运维，VPS 自运维。
