GoogieHost vs FreeHosting.com vs FreeHostia

核实于 2026-11-13 · 本页更新于 2026-11-13

免费子域名有无

GoogieHost：1 个网站 + 免费子域名（后缀三处写法不一致：whf.bz/cu.ma、hf.bz、googiehost.com）。FreeHosting.com：必须使用自己控制的注册域名，不托管免费子域名；不接受 .TK/.ML/.GA 等免费域名。FreeHostia：计划页列出 5 个托管域名与 15 个子域名（TOS），免费子域名计划页未列。

SSL 是否免费

GoogieHost：免费 SSL 证书自动激活，HTTPS 从第一天起可用。FreeHosting.com：免费档不含免费 SSL，HTTPS + 免费 SSL 证书是 $29.95 一次性附加包。FreeHostia：Security 节列出 Let's Encrypt SSL 证书。

数据库大小

GoogieHost：数量两页表述不一致（套餐表 1 个库 vs PHP 页“多个库”）。FreeHosting.com：1 个 MySQL 数据库，InnoDB、phpMyAdmin、无查询数/查询时间限制；+1 个库 $24.95 一次性附加包。FreeHostia：1 个 MySQL v.5 数据库，10 MB 存储；每小时查询与并发限制见 TOS 的 CPU 条款。

常见问题

没有域名，三家选哪家？

GoogieHost 有免费子域名。FreeHosting.com 必须自有域名。FreeHostia 的免费子域名在计划页未列，以官方页面为准。核实于 2026-11-13。

三家谁的 SSL 免费？

GoogieHost 免费 SSL 自动激活；FreeHostia 列出 Let's Encrypt SSL 证书。FreeHosting.com 的 SSL 是 $29.95 一次性附加包。核实于 2026-11-13。
