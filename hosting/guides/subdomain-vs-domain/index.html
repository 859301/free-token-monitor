免费子域名 vs 自有域名

核实于 2026-11-13 · 本页更新于 2026-11-13

免费子域名零成本起步，但后缀归主机商、Cloudflare 在部分免费子域名上不能用；自有域名自己控制、可迁移，但需要先注册域名。FreeHosting.com 必须自有域名。GoogieHost 的免费子域名后缀三处写法不一致。域名过期与站点归属风险见本页末尾。

免费子域名后缀列表

InfinityFree：25+ 免费子域名后缀。Byet.host：24 个免费子域名后缀。x10Hosting：x10.mx、x10.bz、elementfx.com、x10.network。GoogieHost：三处写法不一致——免费页写 whf.bz/cu.ma，FAQ 写 hf.bz，PHP 页写 yourproject.googiehost.com。ProFreeHost：免费子域名（后缀未列）。FreeHosting.com：无免费子域名，必须自有域名。AwardSpace、HelioHost、FreeHostia、TinkerHost 的免费子域名后缀在官网已读页面中未列，以官方页面为准。

绑定与 DNS/NS

自有域名绑定方式各家不同：InfinityFree 与 Byet.host 可自带域名；FreeHosting.com 设置域名服务器 NS1.FREEHOSTING.COM 与 NS2.FREEHOSTING.COM；GoogieHost 官网称自有域名可以指向。绑定步骤以各家官网与面板为准。

Cloudflare 限制

InfinityFree 论坛指南：免费子域名上不能用 Cloudflare，自有域名可以。ProFreeHost 的 Features 页列出 Cloudflare 支持。TinkerHost 免费页写 Cloudflare 兼容。其余主机以官方页面为准。

域名过期与站点归属风险

免费子域名归主机商，主机商停服或删站时子域名随之失效。自有域名自己控制，主机换了域名还能用，但域名过期未续费会被收回。重要站点用自有域名，内容与备份分开存放。
