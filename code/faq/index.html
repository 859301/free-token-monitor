中文问题

个人项目代码放哪？私有仓库免费吗？

GitHub Free：无限公开/私有仓库，免费；但对比表多项功能仅限公开仓库。GitLab Free：$0，注册无需信用卡，每个顶级组 5 名用户。两家均为免费层，选法见个人项目代码放哪。

GitHub Free 私有仓库有哪些功能限制？

对比表中 Free 列的多项功能仅限公开仓库：repository rules、code owners、草稿 PR、Pages 与 wikis、secret scanning 等，私有仓库不可用。完整说明见私有仓库限制说明。

GitHub Free 每月有多少 CI/CD 分钟？

2,000 分钟/月。公开仓库 Actions 分钟免费，公开仓库 Packages 也免费。详情见GitHub Free 详情。

GitLab Free 每月有多少计算分钟？

400 计算分钟/月。另有 10 GiB 可调存储与每月 5 GiB 传输数据。详情见GitLab Free 详情。

GitHub 的 2,000 分钟和 GitLab 的 400 分钟能直接比较吗？

不能直接等同：GitHub 的是 CI/CD 分钟（Actions 分钟），公开仓库免费；GitLab 的是计算分钟。两家按各自计划口径计量，见CI 分钟数对照。

GitHub Free 注册要绑信用卡吗？

官网已读页面中未述绑卡要求，以官方页面为准。

GitLab Free 注册要绑信用卡吗？

不需要。定价页写明“No credit card required”（无需信用卡）。但使用共享 Runner 须绑卡验证，见GitLab Runner 说明。

GitLab 共享 Runner 为什么要绑卡？$1 会扣掉吗？

定价页 FAQ 写明共享 Runner 须绑卡验证；$1 为授权验证，不扣费。定价页未述绑卡原因，见GitLab Runner 说明。

自带 Runner 还要绑卡吗？

不需要。定价页 FAQ 写明：自带 Runner 或禁用共享 Runner 不需要绑卡。

GitLab Free 一个组能加多少人？

每个顶级组 5 名用户。超出 5 名用户的安排在官网已读页面中未述，以官方页面为准。

GitHub Free 的 Codespaces 免费时间怎么算？

免费小时分配给个人账户，不给免费组织；定价页示例：2 核机器 60 小时、4 核 30 小时。Codespaces 访问带 $0 spend limit。详情见GitHub Free 详情。

GitHub Free 的 Packages 存储有多少？

500 MB。公开仓库 Packages 免费。

GitLab Free 的存储和传输额度是多少？

10 GiB 可调存储，每月 5 GiB 传输数据。

GitLab Ultimate 是什么价格？

无公开价。定价页写“Contact us for custom pricing”，按单报价。Premium 为 $29/用户/月，按年计费。详情见GitLab Free 详情。
