三家 5 用户档的区别

GitLab Free 的 5 名用户按顶级组计算；Bitbucket Free 的 5 名用户按工作区计算，构建分钟与存储由工作区内所有用户共享；Azure DevOps 的前 5 名免费用户是 Basic 许可，组织可加无限用户免费访问 Pipelines 与 Artifacts，但访问 Repos 与 Boards 须买 Basic 许可。计算单位不同，同一团队规模在三家的含义不同。

超过 5 人

GitLab：Premium $29/用户/月，按年计费；Ultimate 报价制。Bitbucket：付费档价格在定价页与文档页说法不同（Standard 定价页 $3.65、文档页 $3；Premium 定价页 $8、文档页 $6），以官方页面为准。Azure DevOps：第 6 名起 $6/用户/月；Basic + Test Plans $52/用户/月。

未述人数上限的两家

GitHub Free：人数上限在官网已读页面中未述，仓库无限。Codeberg：人数上限在官网已读页面中未述，但默认每用户/组织 100 个仓库，且仅面向自由/开源软件项目，私有内容至多 100 MB。
