仓库与人数

GitHub Free：无限公开/私有仓库，人数上限在官网已读页面中未述。GitLab Free：每个顶级组 5 名用户，仓库数量在官网已读页面中未述。

CI 分钟

GitHub Free 每月 2,000 CI/CD 分钟，公开仓库 Actions 分钟免费；GitLab Free 每月 400 计算分钟。两家按各自计划口径计量，数字不宜直接等同，见CI 分钟数对照。

存储与传输

GitHub Free：500 MB Packages 存储，公开仓库 Packages 免费。GitLab Free：10 GiB 可调存储，每月 5 GiB 传输数据。

绑卡要求

GitLab Free 注册无需信用卡，但共享 Runner 须绑卡验证（$1 授权验证，不扣费）。GitHub Free 的绑卡要求在官网已读页面中未述。

付费计划

GitHub：Team $4/用户/月（3,000 分钟、2 GB），Enterprise $21/用户/月（50,000 分钟、50 GB）。GitLab：Premium $29/用户/月，按年计费；Ultimate 无公开价，报价制。
