用户与许可

定价页写明：前 5 名 Basic 用户免费，之后 $6/用户/月。FAQ 写明：组织可加无限用户，均可免费访问 Pipelines 与 Artifacts；启用 Repos 或 Boards 后，前 5 名用户免费得 Basic 许可，之后的用户默认 Stakeholder 层，访问 Repos 与 Boards 须买 Basic 许可。Visual Studio 订阅者免费访问 Azure DevOps，且不计入 5 名免费用户。

流水线分钟

每个组织每月 1 个 Microsoft-hosted 并行作业、1,800 分钟（30 小时）构建时间，另有 1 个免费 self-hosted agent、1 个分钟不限的并行作业。免费构建量每月 1 日重置。买第一个 Microsoft-hosted 作业后，并行作业数仍为 1，只解除免费流水线的时间限制；要同时跑 2 个作业须买 2 个 Microsoft-hosted 作业。额外作业：Microsoft-hosted 每月 $40、self-hosted 每月 $15。

Artifacts

每组织 2 GiB 免费，之后按阶梯价计费：2–10 GiB 每 GiB $2、10–100 GiB 每 GiB $1、100–1,000 GiB 每 GiB $0.5、1,000 GiB 以上每 GiB $0.25。

付费计划

Basic $6/用户/月；Basic + Test Plans $52/用户/月。定价页首注明价格为估算，不是实际报价，实际价格可能因协议、购买日期与汇率而异。
