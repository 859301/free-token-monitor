1. 自托管是什么

自托管是把代码托管软件装在自己的服务器上：仓库、Issue、CI 都跑在自己的机器上，数据在自己手里，升级、备份、安全更新也由自己负责。托管服务则由厂商运行基础设施，用户按厂商的计划、额度与规则使用，免费档有各自的人数、分钟与存储上限。

2. Forgejo 自托管

Codeberg FAQ 写明：Forgejo 是 Codeberg 运行的 Git 托管软件，是自由软件，相对容易自托管；商业项目需要私有仓库时，FAQ 建议自托管 Forgejo，而不是用 Codeberg 托管商业私有代码。Codeberg 本身是 Forgejo 的一个托管实例，仅面向自由/开源软件项目，见Codeberg 免费托管。

3. SourceHut 自托管与托管版

SourceHut 定价页写明：SourceHut 100% 开源，有自己的基础设施时可以自己运行，并有安装文档。托管版 sr.ht 是付费服务：托管自有项目的用户应按能力付费，各档功能相同；public alpha 期间多数服务付款可选，但构建服务 builds.sr.ht 与聊天服务 chat.sr.ht 须付费，列表可能变化。托管版没有免费档数字，因此不在免费档列表范围内。

5. 怎么选

看四点：项目是否公开、团队几个人、CI 任务量、是否愿意自己运维。公开的自由/开源软件项目可选 Codeberg 或 GitHub Free（公开仓库 Actions 分钟免费）；5 人小团队对照5 人团队选哪家；CI 任务量大时对照构建分钟对照；不接受厂商规则与额度、且愿意自己运维时，再考虑自托管 Forgejo 或 SourceHut。
