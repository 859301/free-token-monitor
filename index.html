常见问题

按用户实际提问的措辞整理，答案以本站核对的额度数据为准。查看 18 个问题的完整回答。

有哪些完全免费且无需绑定信用卡的 AI API？

本站在架的 43 条额度里，按核对的门槛字段明确要求绑卡的只有 2 条（Cerebras、Vercel AI Gateway）；其余都不要求绑卡，用首页「免绑卡」筛选即可。领取前仍以厂商官方页为准。

免费 AI API 的限速指标 RPM、RPD、TPM 分别代表什么？额度多久重置？

RPM 是每分钟请求数，RPD 是每天请求数，TPM 是每分钟 Token 数；重置时间各家不同，本站每条的「重置」字段都写明了，例如 Cloudflare 在每天 00:00 UTC（北京时间 08:00）重置。

免费额度到期/用完会扣钱吗？会不会自动转付费？

分三种：用完即停、用完转按量计费、需手动开通后付费才继续计费。本站每条的「注意」事项写明了已知情况，领取前务必在厂商官方页确认有没有「用完即停」类开关。

官方网页版聊天免费与开放平台 API 免费额度是互通的吗？

不互通。网页版聊天免费不等于 API 免费，额度、模型、计费各自独立；网页版能用的模型，API 里可能要单独付费或根本没有。

为什么部分免费模型无法直接接入 Codex CLI 或 Claude Code？

协议不匹配：Claude Code 要求 Anthropic 协议，Codex CLI 要求 Responses API，普通 OpenAI Chat Completions 密钥不能直接用；需要确认工具支持的协议和模型是否支持工具调用。

免费 AI API 的 Base URL 怎么填？需要加 /chat/completions 吗？

看工具要求：有的工具要求填到 /v1，有的工具要求填完整路径，重复加 /chat/completions 会 404；Base URL 以厂商官方文档为准，工具的填写规则以工具官方文档为准。

这些免费 API 在中国大陆能用吗？需要翻墙吗？

本站「国内直连」筛选列出的是核对时标注国内可直连的额度（18 条）；海外厂商的可用性说法不一，需要实时测试。本站未做实时实测，实际以测试结果和厂商官方页为准。

Claude Code 是免费的吗？免费版 Claude 包含 Claude Code 吗？

Claude Code 工具本身免费下载，但调用模型要花 API 额度或订阅；Anthropic 的免费套餐不包含 Claude Code。本站没有收录 Claude Code 的免费额度。

遇到 429 怎么办？是等一分钟还是等到明天？

看撞的是哪种限速：分钟级（RPM/TPM）等一会儿再试，日级（RPD/TPD）要等到重置时间；不要无脑重试，失败请求也可能计入上限。

免费层的数据会被用来训练模型吗？能用于商业用途吗？

各家政策不同。本站只在厂商明确说明时才标注，例如 Gemini 免费层数据可能被用于改进 Google 产品；其余额度的数据与商业用途政策以厂商官方条款为准。

Are free LLM APIs really free?

是真的免费，但「免费」分四种形态：长期免费层、注册赠金、周期重置、限时活动；形态不同，有效期、限速、用完后的处理都不同，领取前要看清是哪一种。

Do free AI APIs require a credit card?

本站在架的 43 条额度里，按核对的门槛字段明确要求绑卡的只有 2 条（Cerebras、Vercel AI Gateway）；其余都不要求绑卡，但可能要求注册、手机号或实名。

Is Nano Banana / Veo free on the API?

不是。App/网页版的免费不等于 API 免费；按调研来源，Nano Banana 图像 API 和 Veo 都没有免费层，创建 API Key 不等于获得免费图片额度。

OpenRouter 免费模型每天 50 次，充 $10 后真的是 1000 次吗？

按本站核对的额度原文：20 RPM / 50 次每天，账户充过 $10 后 1000 次每天；失败请求也计入每日上限，免费模型清单会变动。核实于 2026-10-27。

学生优惠还有哪些？Cursor 学生免费 Pro 还能领吗？

Cursor 学生免费 Pro 已于 2026-06-25 结束，不能领了。本站在架的学生额度只有 Kiro 学生计划（每月 1,000 Credits × 12 个月，不结转），需学生身份与实名验证。

Claude Max / ChatGPT 订阅送的 API 额度怎么领？能用于 Claude Code 吗？

通过关联的 Console 组织领取；按调研来源，这类额度不能用于交互式 Claude Code。本站未收录这类捆绑额度，领取前请以 Anthropic / OpenAI 官方页为准。

免费额度没用完会结转到下个月吗？

绝大多数不结转。本站每条的「重置」字段写明了是否结转，例如 ModelScope 每天 250 魔粒「当日不用不结转」，WorkBuddy 500 积分「当月不用作废」，Kiro 学生计划「不跨月结转」。

GitHub Models 还能免费调用吗？

不能。GitHub Models 已于 2026-07-30 退役；需要免费大模型 API 的话，看本站在架的其他额度，例如 Gemini、Groq、OpenRouter、智谱 GLM Flash。
