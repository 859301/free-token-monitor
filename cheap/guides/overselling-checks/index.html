超售与 CPU 争抢：怎么验一台廉价 VPS

本页更新于 2026-11-13

便宜 VPS 的 CPU 通常是共享的：HostEONS 套餐表写 Fair Share（公平共享），DigitalOcean 定价页写 Basic 是共享 CPU、适合突发负载。验机方法：基准测试看单核性能，steal 指标看 CPU 争抢程度，长期观察看稳定性。持续高 steal、IO 极不稳定，就是超售严重的信号——该换就换。

本指南是验机方法，不含基准测试数值（数值随机器与时间变化，无法核实）。厂商说法照录官网页原文。

三种 CPU 说法

HostEONS 套餐表：Fair Share（公平共享）——CPU 资源与其他用户共享，繁忙时性能波动。DigitalOcean 定价页：Basic 是共享 CPU，适合突发负载（bursty workloads）——短时爆发可以，持续满载不行。RackNerd specials 页：称 Full KVM for dedicated resources（厂商说法，未独立验证）。三种说法，两种明确共享、一种厂商自称独占——预期按「共享」放，心态最稳。

怎么验

  • 基准测试：YABS、Geekbench 等工具跑单核与多核分数、磁盘 IO、网络速度——同一台机器不同时段跑 3 次，看波动范围。
  • steal 指标：top 或 vmstat 里看 %steal——持续高于 10% 说明 CPU 争抢严重；偶尔 spike 正常，长期高位不正常。
  • 长期观察：跑 7 天日常负载，记录响应时间与宕机；便宜机器的稳定性，7 天能看出大半。

预期管理

$21/年的机器，合理预期是：轻量服务稳定跑、突发负载能顶、偶尔波动可接受。不合理预期是：持续满载、7×24 高性能、零波动。需求超过预期的，加钱上更高档或换独占 CPU——不要指望 $21/年跑出 $200/年的性能。

常见问题

steal 高怎么办？

先确认是不是自己的负载问题；排除后持续高 steal，说明宿主机超售严重——联系客服或换机。

基准测试跑多少分算好？

没有统一标准：看同价位横向对比与自身需求。分数够用、波动小，就是好机器。
