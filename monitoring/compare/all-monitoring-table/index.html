三处需要留意的口径

  • Sentry 的三项数字未标注周期：对比表原文为 5k errors、5M spans、50 replays，三行本身未标注周期；页面上唯一带 per month 的是新用户推广语。见Sentry 免费额度怎么读。
  • UptimeRobot 的 SSL 监控有两种说法：Free 计划卡片列出“SSL & Domain exp. monitor”，对比表 SSL monitoring 行与 Domain exp. monitoring 行 Free 为 ✗。见UptimeRobot 详情页并列呈现。
  • Plausible 是试用、不是免费层：30 天免费试用，云端无永久免费计划，试用后需预付费方可继续使用。见Plausible 详情页。
