自托管监控路线

核实于 2026-11-13 · 本页更新于 2026-11-13

自托管监控有三条常被讨论的路线：Uptime Kuma、UptimeFlare、哪吒探针。它们是开源软件，需要自己准备运行环境；参数与部署细节以各自项目页面为准。与之对照的托管路线是 UptimeRobot Free：50 个监控器、5 分钟间隔、基础状态页。

两条路线

监控有两条路线：托管免费层（厂商运行服务，按监控器数量与检测间隔设限）与自托管（自己运行开源软件）。论坛讨论中两条路线都有需求：V2EX 帖子标题《有没有啥自建网页监控推荐？》《有类似 UptimeRobot 的源码吗》，Linux.do 有《开源Status监控页面及探针合集》。HertzBeat 也在论坛分享中出现，回复中有用户认为 Uptime Kuma 更好用。

Uptime Kuma

开源自托管监控软件。在 V2EX《有没有啥自建网页监控推荐？》帖子的回复中被推荐，也出现在 Linux.do 的开源 Status 监控页面合集中。部署方式与参数以项目页面为准。

UptimeFlare

一位开发者自写的 uptime 监控及状态页方案，使用 Cloudflare Workers 部署，按帖子表述可免费部署在 Cloudflare 上、服务挂了可通知。部署方式与参数以项目页面为准。

哪吒探针

探针类自托管方案，在 Linux.do《开源Status监控页面及探针合集》中与状态页方案一并讨论。部署方式与参数以项目页面为准。

自托管需要什么

自托管需要运行环境：VPS 或边缘计算平台。VPS 选项见免费 VPS 列表；边缘计算选项见部署与托管列表。自托管软件的运行、更新与数据保留由自己负责。合集帖中提到 CF Workers、Docker、GitHub Actions 等部署方式。

怎么选

不想自己运维、50 个监控器够用，看 UptimeRobot。需要自己掌控运行环境与数据，看三条自托管路线，参数以各自项目页面为准。状态页的对照见状态页基础。
