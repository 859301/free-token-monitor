状态页基础

核实于 2026-11-13 · 本页更新于 2026-11-13

状态页是对外展示服务状态的页面。UptimeRobot Free 含基础状态页，1 个状态页。自托管路线中，UptimeFlare 按帖子标题表述含状态页，Uptime Kuma 出现在开源 Status 监控页面合集中。状态页的具体功能以各家官方页面与项目页面为准。

状态页是什么

状态页是对外展示服务运行状态的页面，服务正常与否在页面上可见。用户问法中有“Free uptime monitoring with status page?”（免费宕机监控带状态页吗？）。

UptimeRobot 的基础状态页

UptimeRobot Free 计划卡片列出基础状态页（basic status page）与 1 个状态页。状态页的自定义程度、订阅通知等细节在官网已读页面中未述，以官方页面为准。

自托管状态页路线

UptimeFlare：帖子标题为《自己写的 uptime 监控及状态页 UptimeFlare, 使用 Cloudflare Workers 部署》。Uptime Kuma：出现在 Linux.do《开源Status监控页面及探针合集》中。部署方式与参数以各自项目页面为准，路线见自托管监控路线。

怎么选

需要现成的托管状态页，看 UptimeRobot 的基础状态页。需要自己掌控状态页的运行环境，看自托管路线。
