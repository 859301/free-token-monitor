平台自带能力在哪里看

Cloudflare Cron Triggers 与 Queues 随 Cloudflare Workers 提供；Vercel Cron 随 Vercel 部署平台提供；Render Cron Jobs 随 Render 免费档提供；GitHub Actions 定时触发随 GitHub Free 的 2,000 分钟提供。各平台的免费档细节见对应详情页。

独立服务多提供了什么

独立服务单独计量，能力按各自官方页写明：QStash 提供排程、延迟最长 7 天、默认重试 3 次与 DLQ；Workflow 提供多步骤工作流与等待事件；Inngest 提供步骤重试、睡眠与 30 天运行；Trigger.dev 提供无最长运行时长的任务与等待不计费。平台自带能力的排程细节以各平台官方页为准。

安排原则

主栈自带的排程能力够用时，优先用主栈自带的，减少一个外部依赖；需要独立重试、延迟、死信队列、跨平台触发或更长的任务运行时长时，再看独立服务。两边计量口径不同，对照时只看同口径数字。
