免费的范围与条款边界

服务条款第 1 条：服务完全免费，无需付费。服务条款第 4 条：不提供任何形式的保证，包括可用性与性能保证，不承担责任。第 6 条：服务可随时无事先通知关闭；账号可无事先通知删除或锁定。第 7 条：服务不适用于处理个人数据、敏感公司数据或其他机密数据；URL、请求头、请求体中不得传输机密、密码与个人数据。

任务数量上限、执行次数上限、超时默认值、响应数据上限、历史保留数量、重试规则在已读官方页面中未述，以官方页面为准。

排程与 API

排程字段为分钟、小时、月中日、月、周中日；minutes [-1] 为每分钟。每个任务可设时区，默认 UTC；超时按任务以秒配置，-1 为使用默认超时，默认值未述。

REST API 默认每天 100 次请求，sustaining 会员 5,000 次；任务创建限速 1 次/秒、5 次/分钟；列表、详情、历史限速 5 次/秒；超限返回 429。

Sustaining 会员

Sustaining 会员按月或按年自愿付费，不产生额外权益（范围、功能、可用性）；额外功能或放宽限制只在自愿基础上酌情提供。会员可随时取消，期末生效，权益撤销。

超限规则与付费档
