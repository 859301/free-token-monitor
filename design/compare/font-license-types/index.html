OFL 的关键条件

以思源字体 LICENSE.txt 为据：可商用、可修改、可再分发；修改版不得使用保留字体名称；字体软件不得单独出售，可捆绑出售；再分发须附版权声明与许可；用字体创建的文档不受 OFL 再分发条件约束；Logo 文字用途未明示。

Apache 许可：只有提及，没有全文

Google Fonts FAQ 写部分字体适用 Apache 许可；Apache 许可文本本次未读，本页不展开其条件。所用字体适用 Apache 许可时，以该字体的许可文本为准。

厂商自有许可：以官方页面为准

厂商自有许可各家不同，须逐家读官方授权页全文。阿里巴巴普惠体等字体的官方授权页信息未能确认，以官方页面为准，本页不写授权结论。

常见问题

OFL 字体能商用吗？

能。以思源字体 LICENSE.txt 为据，OFL 许可免费授予使用、学习、复制、合并、嵌入、修改、再分发与出售副本的权利，条件是改后换名、不得单独出售、再分发附声明。

Apache 许可的字体有什么限制？

Apache 许可文本本次未读，以各许可文本为准。Google Fonts FAQ 只写部分字体适用 Apache 许可。

厂商字体都能按 OFL 理解吗？

不能。厂商自有许可各家不同，须逐家读官方授权页全文；官方授权页信息未能确认的，以官方页面为准。
