Active user and connection definitions

The official FAQ states: a user counts as active when performing any user action (for example: sign up, sign in, or profile update) within the calendar month. A connection is the relationship between WorkOS and any group of end users; each enterprise customer supported with SSO or Directory Sync counts as one connection.

What the free tier includes

The User Management free allowance covers up to 1,000,000 MAU, including: social auth (Microsoft, Google, and more), email + password (with automatic password strength and leak detection), Magic Auth (six-digit codes sent via email), MFA (TOTP and SMS), email verification, organization auth policies, just-in-time (JIT) user provisioning, biometric / passkey auth, role-based access control (RBAC), and CLI authentication. Capturing and exporting audit log events is free. All products are available in staging to try at no cost. Support for all accounts includes email support, in-dashboard web support, API status notifications, docs and example apps.

Overage rules and paid tiers

User Management: $2,500 per month per additional 1 million users. Single Sign-On: the official blog states $125 per connection per month, with automatic volume discounts that step down as usage scales. Directory Sync: the official blog states $125 per connection per month. Audit logs: log streaming $125 per SIEM connection per month; event retention $99 per month per million events stored. Custom domains: the pricing page FAQ states an additional monthly fee applies; the official blog states $99 per month (flat rate).

FAQ

How large is the WorkOS free allowance?

User Management is free up to 1,000,000 MAU; active means performing any user action (sign up, sign in, profile update, and similar) within the calendar month. Each additional 1 million users costs $2,500 per month. Verified 2026-11-14.

Is WorkOS SSO free?

No. SSO and Directory Sync include no free connections; the official blog states $125 per connection per month each, with automatic volume discounts for SSO. Verified 2026-11-14.

Does WorkOS need a credit card?

Not to start. The official FAQ states no credit card is needed until moving to production. Verified 2026-11-14.
