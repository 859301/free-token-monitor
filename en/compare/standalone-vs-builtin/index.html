Where platform built-ins are covered

Cloudflare Cron Triggers and Queues come with Cloudflare Workers; Vercel Cron comes with the Vercel deploy platform; Render Cron Jobs come with the Render free tier; GitHub Actions scheduled triggers come with GitHub Free and its 2,000 minutes. Free tier details for each platform appear on the corresponding detail pages.

What standalone services add

Standalone services meter separately, with capabilities stated on each official page: QStash provides schedules, a 7-day maximum delay, 3 retries by default, and a DLQ; Workflow provides multi-step workflows with event waits; Inngest provides step retries, sleeps, and 30-day runs; Trigger.dev provides tasks with no maximum duration and waits not billed. Platform built-in schedule details follow each platform official page.

Arrangement principle

When built-in scheduling on the main stack covers the need, built-in scheduling keeps the setup simpler, with one fewer external dependency; independent retries, delays, dead-letter queues, cross-platform triggers, or longer task durations point toward standalone services. Metering units differ across both sides, so comparison stays within one unit at a time.
