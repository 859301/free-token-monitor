GitHub Free vs GitLab Free

Updated 2026-11-14 · Table data from vendor official pages (verified 2026-11-13)

Short answer: both are $0 free tiers with different metering: GitHub Free places no limit on repository counts, with 2,000 CI/CD minutes per month and 500 MB Packages storage; GitLab Free allows 5 users per top-level group, with 400 compute minutes per month, 10 GiB adjustable storage, and 5 GiB data transfer per month. Several GitHub features in the comparison table are limited to public repositories; GitLab sign-up needs no credit card, but shared runners require card verification.

Repositories and users

GitHub Free: unlimited public/private repositories; user limits are not stated on the official pages read. GitLab Free: 5 users per top-level group; repository counts are not stated on the official pages read.

CI minutes

GitHub Free: 2,000 CI/CD minutes per month, with public repository Actions minutes free; GitLab Free: 400 compute minutes per month. Each plan meters by its own rules, so the figures cannot be equated directly — see CI minutes compared.

Storage and transfer

GitHub Free: 500 MB Packages storage, with public repository Packages free. GitLab Free: 10 GiB adjustable storage, 5 GiB data transfer per month.

Card requirements

GitLab Free sign-up needs no credit card, but shared runners require card verification ($1 authorization check, no charge). GitHub Free card requirements are not stated on the official pages read.

Paid plans

GitHub: Team $4/user/month (3,000 minutes, 2 GB), Enterprise $21/user/month (50,000 minutes, 50 GB). GitLab: Premium $29/user/month, annual billing; Ultimate has no public price (quote-based pricing).

FAQ

Which plan has more free minutes?

By the numbers, GitHub Free has 2,000 CI/CD minutes per month and GitLab Free has 400 compute minutes per month. Each plan meters by its own rules, with different names and scopes, so the figures cannot be equated directly; GitHub public repository Actions minutes are free. Verified 2026-11-13.

Which sign-up needs no card?

The GitLab Free pricing page states “No credit card required”, but shared runners require card verification. GitHub Free card requirements are not stated on the official pages read. Verified 2026-11-13.
