Build minutes compared

Updated 2026-11-14 · Table data from vendor official pages (verified 2026-11-13 and 2026-11-14)

Short answer: CI time goes by a different name on each of the 5 free tiers: GitHub counts CI/CD minutes (Actions minutes), GitLab counts compute minutes, Bitbucket counts build minutes, Azure DevOps counts pipeline minutes, and Codeberg states no monthly minute figure. The figures cannot be equated directly: GitHub Actions minutes are free for public repositories, Bitbucket build minutes scale by runner size, Azure DevOps adds 1 self-hosted job with unlimited minutes, and Codeberg runs CI on a request basis.

Metering rules

The Bitbucket pricing page states that build minutes scale by runner size: a 5-minute step on a 2x runner counts as 10 minutes, and build minutes are shared by all users in the workspace. Azure DevOps grants each organization 1 Microsoft-hosted parallel job with 1,800 minutes per month, with free amounts resetting on the first day of the month. Scaling rules for GitHub and GitLab are not stated on the official pages read. Codeberg states no monthly minute figure; the FAQ asks for requests before exceeding default resources.

Bring-your-own runners and jobs

GitLab Free: bring-your-own runners, or disabling shared runners, need no card. Azure DevOps: 1 free self-hosted agent running 1 parallel job with unlimited minutes, with extra self-hosted jobs at $15 per month. Codeberg: dedicated runners are available on request when default runners are not enough. Bring-your-own arrangements for GitHub and Bitbucket are not stated on the official pages read.

Past the allowance

Bitbucket: 1,000 more minutes or 100 GB for $10 per month; the documentation page states no overage protection on the Free plan. Azure DevOps: free amounts reset on the first day of the month, or extra parallel jobs can be bought. Codeberg: requests are needed before exceeding default resources. Behavior after minutes run out is not stated on the official pages read for GitHub and GitLab — check the official page.

FAQ

Which free tier offers the most minutes?

By the numbers: GitHub Free 2,000 CI/CD minutes per month, Azure DevOps 1,800 pipeline minutes per month, GitLab Free 400 compute minutes per month, Bitbucket Free 50 build minutes per month; Codeberg states no monthly minute figure. Each plan meters by its own rules, with different names and scopes, so the figures cannot be equated directly. Verified 2026-11-13 and 2026-11-14.

What happens when the minutes run out?

Bitbucket offers 1,000 more minutes or 100 GB for $10 per month; Azure DevOps free amounts reset on the first day of the month, with extra parallel jobs available for purchase; Codeberg asks for requests before exceeding default resources. Behavior after minutes run out is not stated on the official pages read for GitHub and GitLab — check the official page. Verified 2026-11-13 and 2026-11-14.
