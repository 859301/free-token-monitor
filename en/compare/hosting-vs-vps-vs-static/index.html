Web hosting vs VPS vs static hosting

Updated 2026-11-14 · Table data from vendor official pages (verified 2026-11-13)

Short answer: the three services differ in capability: web hosting provides space that runs PHP and connects to MySQL, with WordPress installable and no maintenance; a VPS provides a server with root access (EUserv VS2-free as an example: IPv6-only, monthly manual renewal), with the environment installed by hand; static hosting serves HTML/CSS/JS only, with no PHP and no MySQL, so WordPress cannot run. Discourse and Node apps need a runtime of their own, which PHP web hosting cannot run.

Web hosting

Web hosting provides space that runs PHP and connects to MySQL, with a panel and a one-click installer, for WordPress, blogs, and business sites, with no maintenance. Limits are written on each vendor’s official site: space, traffic/hits, database counts, PHP versions, idle and removal rules. The 10 hosts on the Web hosting list are all web hosting.

VPS: EUserv as an example

EUserv VS2-free is a container-type vServer with full root access: 1 core @ 1 GHz, 1 GB memory, 10 GB disk, 1 TB traffic per month. The basic tier has no free IPv4 address and 1 free IPv6 address /128; the contract term is 1 month, renewed manually. A VPS has no PHP/MySQL panel-hosting semantics: environment, database, and security are all installed and managed by hand. Other free VPS forms (Oracle Always Free, GCP e2-micro, and others) are on Free VPS.

Static hosting

Static hosting publishes HTML, CSS, JavaScript, and other static files only, with no server-side PHP and no MySQL; WordPress cannot run, and dynamic programs cannot run. GitHub Pages, Netlify, and Cloudflare Pages belong in this category — see Deploy &amp; hosting and the static hosting comparison. Static hosting is outside the verification scope of the web hosting pages; it appears here only to mark the capability boundary.

FAQ

Can a Discourse forum run on free web hosting?

No. Discourse needs a runtime of its own (Ruby, PostgreSQL, Redis, and others), which PHP web hosting does not have. A forum user asked the same question, and the reply was that InfinityFree is PHP web hosting and cannot run it (a user statement). Running Discourse needs a VPS, with the environment installed by hand.

Which service fits WordPress?

WordPress needs PHP + MySQL: web hosting installs it directly (one-click installer), a VPS installs it with a hand-built environment, static hosting cannot run it. Web hosting needs no maintenance; a VPS is self-managed.
