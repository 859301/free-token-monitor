Standalone services

R2 and B2 are standalone object storage services, each with a detail page: R2 with a monthly free tier and egress free of charge; B2 pay-as-you-go with the 3x egress rule. Head-to-head comparison: Cloudflare R2 vs Backblaze B2.

Database-bundled storage

Supabase Storage: 1 GB file storage, provided with the Supabase plan; details on the Supabase detail page. Firebase Storage: the pricing page Spark plan column reads “Not applicable”, with free allowances in the Blaze column; details on the Firebase detail page.

How to choose

For a standalone object storage service, compare the R2 and B2 detail pages. For projects already using Supabase or Firebase, compare the database detail pages for the bundled-storage wording. Egress rules: see Egress rules compared.
