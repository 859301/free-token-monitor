China cloud SMS compared: Alibaba Cloud vs Tencent Cloud

Published 2026-11-16 · Updated 2026-11-16 · Verified 2026-11-15

Alibaba Cloud and Tencent Cloud both require signatures and templates to pass review before use, and both limit individual users: Alibaba Cloud individual self-use qualifications fail real-name signature registration, while Tencent Cloud individuals may only send verification and notification messages. Trial and gift allowances are both one-time 3-month allowances: Alibaba Cloud trial pack 100 messages for individuals and 200 for enterprises, Tencent Cloud first-activation gift 200 for enterprises and 100 for individuals. Mainland package prices both sit in the CNY 0.041–0.05 per message range. Verified 2026-11-15.

Individual vs enterprise differences

Both vendors distinguish individuals from enterprises: Alibaba Cloud individual self-use qualifications fail real-name signature registration, requiring a third-party qualification or an enterprise upgrade, and individually verified users cannot apply for promotion templates; Tencent Cloud individuals may only send verification and notification messages, not marketing, with only enterprise-verified users able to send domestic marketing SMS. Account type should be confirmed before applying for a signature.

Review times

Alibaba Cloud qualification review usually completes within 2 working days, with carrier real-name registration averaging 5–7 working days and 7–10 for some carriers, with no timing guarantee from carriers. Tencent Cloud signature and template review normally returns feedback in about 2 hours, with carrier filing after approval generally taking 7–10 working days. Both filing stages count in working days, so time planning should follow the filing figures.

Price structures

Both mainland package prices sit in the CNY 0.041–0.05 per message range, valid 2 years. Alibaba Cloud international USD prices and mainland CNY prices belong to two separate sites, as do Tencent Cloud international USD and mainland CNY prices. Under pay-as-you-go, Alibaba Cloud China pricing is $0.0500 per message, while Tencent Cloud mainland SMS is prepaid and requires a package first.

FAQ

Can individuals send domestic SMS?

Verification and notification messages, with limits: Alibaba Cloud individual self-use qualifications fail real-name signature registration, and Tencent Cloud individuals may only send verification and notification messages, not marketing.

How long does review take?

Alibaba Cloud qualification review usually takes 2 working days with carrier registration at 5–7 working days; Tencent Cloud signature and template review takes about 2 hours with carrier filing at 7–10 working days.

How do packages differ from pay-as-you-go?

Packages are prepaid with validity periods; Alibaba Cloud defaults to resource packages with lower in-package per-message prices than pay-as-you-go, which requires sales contact, and Tencent Cloud mainland SMS requires a package first.
