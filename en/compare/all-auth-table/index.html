Units of measurement

Clerk MRU: a user counts as retained when returning 24 hours after signing up. Auth0 MAU: officially worded “External Active Users”. Descope MAU: a user signing up or signing in in 1 month. Frontegg MAU: a user logging in at least once in a calendar month. WorkOS active user: a user performing any user action in a calendar month. Logto also counts tokens, and only access tokens are counted. Stytch monthly active user and agent counting details, and Supabase Auth and Firebase Auth MAU counting details, follow the official pages. The units differ, so the numbers cannot be compared directly by size.

FAQ

Can the 10 auth allowance numbers be compared directly by size?

No. Clerk counts MRU (a user counts as retained when returning 24 hours after signing up); the other 9 count MAU (Stytch counts monthly active users and AI agents). The units differ. 6 new entries verified 2026-11-14; the other 4 verified 2026-11-13.

Where are the full specs for Supabase Auth and Firebase Auth?

On the database detail pages: Supabase Auth comes with the Supabase free tier (50,000 MAU), Firebase Auth comes with the Firebase free allowances (50K MAU). Verified 2026-11-13.
