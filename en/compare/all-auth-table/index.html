Units of measurement

Clerk MRU: a user counts as retained when returning 24 hours after signing up. Auth0 MAU: officially worded “External Active Users”. Supabase Auth and Firebase Auth MAU counting details follow the official pages. The units differ, so the numbers cannot be compared directly by size.

FAQ

Can the 4 auth allowance numbers be compared directly by size?

No. Clerk counts MRU (a user counts as retained when returning 24 hours after signing up); Auth0, Supabase, and Firebase count MAU. The units differ. Verified 2026-11-13.

Where are the full specs for Supabase Auth and Firebase Auth?

On the database detail pages: Supabase Auth comes with the Supabase free tier (50,000 MAU), Firebase Auth comes with the Firebase free allowances (50K MAU). Verified 2026-11-13.
