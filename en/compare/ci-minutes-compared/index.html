CI minutes compared

Updated 2026-11-14 · Table data from vendor official pages (verified 2026-11-13)

Short answer: GitHub Free: 2,000 CI/CD minutes per month, with public repository Actions minutes free. GitLab Free: 400 compute minutes per month. The two plans meter by their own rules, with different names and scopes, so the figures cannot be equated directly.

What CI minutes are

CI/CD means a platform automatically runs builds, tests, and other tasks after code is committed; CI minutes measure the runner time those tasks consume. More tasks, and longer tasks, consume more minutes.

Metering differences

GitHub minutes are called Actions minutes, a form of CI/CD minutes, free for public repositories; GitLab minutes are called compute minutes. The names and scopes differ, so the 2,000 and 400 figures cannot be equated as multiples under the same metering. Full specs are on the GitHub Free and GitLab Free detail pages.

After minutes run out

Neither official page read states what happens after minutes run out — check the official page. GitHub paid-plan minute counts: Team 3,000 minutes, Enterprise 50,000 minutes.
