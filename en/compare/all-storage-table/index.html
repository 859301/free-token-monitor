FAQ

Which object storage services have a free tier?

Cloudflare R2 has a monthly free tier: 10 GB-month storage, 1M Class A operations, 10M Class B operations, egress free. Backblaze B2 has no free tier and is pay-as-you-go. Supabase Storage and Firebase Storage come with database plans; details are on the database detail pages. Verified 2026-11-13.

Where are the details for Supabase Storage and Firebase Storage?

On the database detail pages: Supabase Storage holds 1 GB file storage, provided with the Supabase plan; Firebase Storage reads “Not applicable” in the Spark plan column, with free allowances in the Blaze column. Verified 2026-11-13.
