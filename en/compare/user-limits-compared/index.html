User limits compared

Updated 2026-11-14 · Table data from vendor official pages (verified 2026-11-13 and 2026-11-14)

Short answer: Three of the 5 free tiers have a user limit: GitLab Free allows 5 users per top-level group, Bitbucket Free allows up to 5 users, and Azure DevOps offers the first 5 Basic users free. GitHub Free and Codeberg user limits are not stated on the official pages read; Codeberg has a default limit of 100 repositories and a free/libre software only scope. Counting units differ — top-level group, workspace, Basic license — so the figures cannot be equated directly.

How the three 5-user offers differ

GitLab Free counts 5 users per top-level group; Bitbucket Free counts up to 5 users per workspace, with build minutes and storage shared by all users in the workspace; Azure DevOps counts the first 5 free users as Basic licenses, while an organization can add unlimited users with free access to Pipelines and Artifacts, and Basic licenses are needed for access to Repos and Boards. Different counting units mean the same team size means different things on each service.

Past 5 users

GitLab: Premium $29/user/month, billed annually; Ultimate uses quote-based pricing. Bitbucket: paid plan prices differ between the pricing page and the documentation page (Standard $3.65 on the pricing page, $3 on the documentation page; Premium $8 on the pricing page, $6 on the documentation page) — check the official page. Azure DevOps: $6/user/month from the 6th user; Basic + Test Plans $52/user/month.

The two offers with no stated user limit

GitHub Free: user limits are not stated on the official pages read, and repositories are unlimited. Codeberg: user limits are not stated on the official pages read, with a default limit of 100 repositories per user or organization, a free/libre software only scope, and private content capped at 100 MB.

FAQ

Which free tiers have a user limit?

Three: GitLab Free allows 5 users per top-level group, Bitbucket Free allows up to 5 users, and Azure DevOps offers the first 5 Basic users free. User limits for GitHub Free and Codeberg are not stated on the official pages read. Verified 2026-11-13 and 2026-11-14.

What happens past 5 users?

GitLab Premium costs $29/user/month (annual billing); Bitbucket paid plan prices differ between the pricing page and the documentation page — check the official page; Azure DevOps charges $6/user/month from the 6th user, with further users defaulting to the Stakeholder tier. Verified 2026-11-13 and 2026-11-14.
