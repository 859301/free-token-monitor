Single-license libraries vs aggregators and communities: why per-item checks are needed

Published 2026-11-15 · Updated 2026-11-15 · Verified 2026-11-14

Why per-item checks are needed

Aggregators do not re-license uniformly: the Iconify collections.md file gives a license for each set, with Apache 2.0, MIT, CC BY 4.0, ISC, and OFL all appearing in the portion read. Community licenses also vary per resource: Figma free files default to CC BY 4.0, plugins and widgets default to the Community Free Resource License, and creators can add or replace terms. Reading only entry-page wording mistakes one set or resource license for the whole.

Iconify check method

Find the set in collections.md, read its license marking and license URL, then follow the attribution or notice retention duties in that set license text; check again when switching to icons from another set. Catalog markings do not replace upstream license texts.

Figma resource page markings

Check the license marking on each resource page before use: free files default to CC BY 4.0 with credit required and are not a public domain license; plugins and widgets use a different default license with no resale or redistribution; creators can add other license types or replace the terms with their own.

FAQ

Can aggregator entry-page wording serve as the basis directly?

No. Entry-page wording does not re-license uniformly; Iconify licenses differ per set and Figma licenses differ per resource — check per set or per resource.

Do icons within one set share a license?

Follow the license marking and license URL of the set; whether exceptions exist inside a set is not verified — check the official page. Check again when switching sets.

Do Figma Community free files and plugins share a license?

No. Free files default to CC BY 4.0; plugins and widgets default to the Community Free Resource License, and creators can add or replace terms.
