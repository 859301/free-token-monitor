Icon licenses compared: Lucide, Heroicons, Font Awesome Free

Published 2026-11-15 · Updated 2026-11-15 · Verified 2026-11-14

All three icon libraries allow commercial use; differences sit in license structure and notice retention: Lucide is ISC plus MIT for some icons, Heroicons is MIT (condition sentence incomplete — follow the full LICENSE file), and Font Awesome Free is a three-license mix with embedded comments covering attribution. Icon counts are not verified for any of the three.

License structure

Lucide and Heroicons each use one main license (plus the Feather-derived MIT part for Lucide); Font Awesome Free applies three licenses by file type, so the file type in use decides the applicable license. Attribution duties differ across the three structures and cannot be swapped between them.

Notice retention differences

Lucide requires copyright and license notices in all copies, covering both the ISC and MIT parts; the Heroicons condition sentence is incomplete in the copy read, so the full LICENSE file governs; Font Awesome Free downloads already contain sufficient embedded attribution comments, and the license page asks users not to remove comments, especially in code.

Brand icon rules

Font Awesome states that brand icons serve only to refer to the company, product, or service represented; the Lucide license page and the Heroicons LICENSE file do not address brand icons — check the official page. Brand icons involve trademark rights; an icon library license is not a trademark license.

FAQ

Can all three icon libraries be used commercially?

Yes. The Lucide ISC text grants use for any purpose, the Heroicons MIT text grants dealing in the software without restriction, and the Font Awesome Free license page expressly allows commercial projects; notice retention requirements differ.

Which attribution route is simplest?

Routes differ: Font Awesome Free relies on embedded comments in downloaded files, with nothing additional needed for normal use; Lucide requires notices retained with copies across both license parts; Heroicons follows the full LICENSE file in the repository.

How many icons does each library have?

Not verified for any of the three. The Lucide license page, the Heroicons LICENSE file, and the Font Awesome license and pricing pages give no icon counts — check the official page.
