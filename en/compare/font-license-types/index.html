Key OFL conditions

From Source Han LICENSE.txt: commercial use, modification, and redistribution allowed; modified versions must not use a Reserved Font Name; font software must not be sold separately, while bundling is allowed; redistribution must carry the copyright notice and license; documents created with the font are not bound by OFL redistribution conditions; logo text use is not addressed.

Apache license: mentioned only, no full text

The Google Fonts FAQ states that some fonts use the Apache license; the Apache license text was not read, so conditions are not expanded here. For a font under the Apache license, follow that font license text.

Vendor licenses differ per vendor; read each vendor official license page in full. Official license page information for fonts such as Alibaba PuHuiTi could not be confirmed — check the official page; no license conclusions are stated here.

FAQ

Can OFL fonts be used commercially?

Yes. From Source Han LICENSE.txt, the OFL grants free rights to use, study, copy, merge, embed, modify, redistribute, and sell copies, with conditions: rename after modification, no separate sale, and notices with redistribution.

What restrictions apply to Apache-licensed fonts?

The Apache license text was not read — check each license text. The Google Fonts FAQ only states that some fonts use the Apache license.

Can vendor fonts be treated like OFL fonts?

No. Vendor licenses differ per vendor; read each vendor official license page in full. Where official license page information could not be confirmed, check the official page.
