China ICP Filing: Overview

Overview · Verified 2026-11-14 and 2026-11-15

Filing (beian) is a Mainland-China-only compliance process and a precondition for launching services on servers located in mainland China. A website or app served from a mainland China server needs an ICP filing number before access can be opened. There is no free-quota concept attached to filing.

Scope note: this page is an overview. The authoritative procedures are published in Chinese by the Ministry of Industry and Information Technology (MIIT) and by the access providers. Filing details in the Chinese-language official pages govern, and individual cases follow the reply of the local communications administration.

Who needs filing

  • Providing non-commercial internet information services within the territory of the People's Republic of China requires filing; without filing, such services must not be provided within the territory (Article 5 of the Filing Measures).
  • A server located in mainland China requires ICP filing through the access provider's platform; a server outside mainland China, including Hong Kong, does not require filing (Alibaba Cloud).
  • Resolving a domain name to a mainland China server IP creates the filing obligation regardless of purpose: intranet penetration, API endpoints, and mail services included. A domain with only an MX record pointing to a mail server, and no website hosting or web service, does not require filing (Alibaba Cloud). Using a non-standard port (other than 80/443) does not change the obligation.
  • Resolving a domain name to a Tencent Cloud mainland China service without filing is detected by an unfiled-site monitoring system and access is blocked, including HTTPS access (Tencent Cloud).

Official timelines, by stage

  • Access-provider preliminary review: 1–2 working days (Alibaba Cloud and Tencent Cloud agree).
  • SMS verification: the MIIT system sends a verification code; verification must be completed within 24 hours. The sending number is 12381 or a 106-prefixed long number, and the code has six digits (Alibaba Cloud). Five consecutive failures lead to a failed filing and automatic return after 24 hours; the SMS can be resent at most 2 times (Alibaba Cloud).
  • Administration review: 1–20 working days, with a statutory limit of 20 working days. The Filing Measures, Article 12: where materials are complete, filing shall be granted within 20 working days, a filing number issued, and the filing information published through the MIIT filing management system. Alibaba Cloud states that administration review cannot be expedited.
  • After a rejection by the administration, about 1 working day is needed for the status to sync to Alibaba Cloud.

Fees, stated separately

  • Tencent Cloud documentation states that Tencent Cloud ICP filing is free of charge, and that filing with Tencent Cloud requires purchasing a qualifying Tencent Cloud service resource (CVM, Lighthouse, Serverless, or another eligible type).
  • The Alibaba Cloud pages read state no free-of-charge or fee statement for filing itself, and Alibaba Cloud operates a filing service-code mechanism that includes paid service codes; purchasing a service code alone cannot complete filing. Server and service-code costs are separate from filing itself.
  • No fee or free-of-charge statement was found in the MIIT interpretation or the Filing Measures text read; check the official page.

Display of the filing number

  • Upon launch, the filing number must be shown at the center of the bottom of the website homepage, with a link below the number to the MIIT filing management system website for public verification (Article 13, current text).
  • For filings in Guangdong Province, the entity filing number is displayed at the bottom of the website; for filings elsewhere, the website filing number is displayed (Alibaba Cloud).
  • An app must show the filing number in a prominent position and link the filing system website below the number; distribution platforms must show the filing numbers of the apps distributed (Notice No. 105, item 8).
  • The 2024 revision deleted the requirement to place an electronic filing verification mark; the current text no longer contains that requirement. Article 25 (current text): failure to link the MIIT filing management system website below the filing number leads to an order to rectify within a time limit, and a fine of CNY 5,000 to CNY 10,000 if rectification is not completed in time.

Public security filing

  • PSB filing is a separate system from ICP filing, with a different authority, system, and number. Completing ICP filing does not complete PSB filing automatically.
  • Article 12 of the Security Protection Measures: filing procedures must be completed within 30 days from the date the network is formally connected, with the accepting authority designated by the local public security authority.
  • Two wordings stand side by side on whether PSB filing is mandatory: Alibaba Cloud documentation states that PSB filing must be completed within 30 days after a website or app is launched, including for overseas servers accessible from within China; Tencent Cloud documentation lists two cases where PSB filing may be deferred for the time being (the website is not actually built and launched, or is not accessible over the public internet; the website only provides API services with no user-facing web content). The local public security authority governs.
  • Tencent Cloud documentation links the platform at beian.mps.gov.cn; Alibaba Cloud documentation links the platform at www.beian.gov.cn. The relationship between the two domains was not verified against the platform's own pages.
  • After PSB approval, within 30 days, the filing number must be copied from the filed website details, the filing-number icon downloaded, the filing-number HTML code copied, and the page source edited (Tencent Cloud documentation).

Individual vs. entity filing

  • Individuals can file. An individual filing order can add at most 1 website with 1 domain name, or at most 1 app service; an entity filing order can add at most 10 websites or 10 services (Tencent Cloud).
  • Where website content relates to an industry or enterprise, filing must be made in the name of an organization (Alibaba Cloud). Tencent Cloud states that individual filing content must not involve enterprises, groups, forums, or commercial sales.
  • Individual filing requires the website or app manager to be the same person as the entity manager (Alibaba Cloud).

After filing

  • Changes to filing information: file a change at least 30 days in advance through the filing system with the original filing authority (Article 14). Termination of service: file a cancellation on the date of termination (Article 15).
  • Changing access providers requires an access filing with the new provider.
  • Annual review: the provincial communications administration conducts an annual review of filings online; providers must complete the annual review through the MIIT filing management system at the prescribed time each year (Articles 20–21). How the annual review is carried out in practice: check the official page.
