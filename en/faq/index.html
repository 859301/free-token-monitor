What do RPM, RPD, and TPM mean? When do quotas reset?

RPM = requests per minute; RPD = requests per day; TPM = tokens per minute. Some vendors also limit TPD (tokens per day). All four axes apply at once — hitting any one returns a 429. Verified examples: Groq is “per model 30 RPM / 1,000 requests per day / 200K tokens per day”; OpenRouter free models are “20 RPM / 50 requests per day”; Gemini free tier is “5–30 RPM / per-model daily caps”. Reset times differ per vendor: Cloudflare Workers AI resets at 00:00 UTC (08:00 Beijing time); Huawei Cloud CodeArts at 24:00 (UTC+8); AMD at 00:00 Beijing time; IFM at 00:00 UTC. See each offer’s “reset” field.

Source: verified listings; verification dates 2026-10-09–2026-11-08.

What happens when I hit a limit or a trial ends? Will I be charged?

It depends on the vendor — three patterns exist. Stops: Tencent Cloud TokenHub notes usage stops without auto-charging — postpaid billing must be enabled to continue. Switches to pay-as-you-go: Alibaba Cloud Bailian switches by default — turn on “stop when exhausted”; Qiniu also switches to pay-as-you-go when used up. Overage billing: You.com bills overage at $5 per 1,000 searches. Where what happens is not stated, confirm on the official page before claiming: is a card required, is there a “stop when exhausted” switch, does anything auto-renew? Never assume “free allowance” means no charge.

Source: verified risk and reset fields; verification dates 2026-10-27–2026-11-01.

I got a 429 error. Should I wait a minute or until tomorrow?

Check which limit you hit. Minute-level limits (RPM/TPM): wait a bit and retry. Day-level limits (RPD/TPD): wait until the reset time. Some vendors send a Retry-After header (suggested wait in seconds) — follow it. Don’t retry blindly: OpenRouter explicitly notes that failed requests also count toward the daily cap, so retrying burns the daily allowance faster. Day-level waits depend on each vendor’s reset time (see the previous question). Longer-term relief: lower concurrency, exponential backoff, and spreading requests across vendors (without violating vendor terms).

Source: verified listings, including the OpenRouter risk note, verified 2026-10-27.

Why can’t some free models plug straight into Codex CLI or Claude Code?

The most common cause is a protocol mismatch. Different tools require different protocols: Claude Code requires the Anthropic protocol; Codex CLI requires the Responses API; Cline, OpenCode, and similar tools mostly use OpenAI-compatible formats. A free key that only offers OpenAI Chat Completions format can’t plug directly into a tool requiring another protocol. The second common cause is a model that doesn’t support function calling, which coding tools rely on. The third is a wrong Base URL — for example, adding /chat/completions twice, which returns a 404. Configuration details are per each tool’s official docs; listings mark which offers are OpenAI-compatible (23 of 43).

Source: research notes; verified OpenAI-compatibility fields.

How do I fill in the Base URL? Do I need to add /chat/completions?

There is no single answer — it depends on the tool. Some tools want the Base URL ending at /v1 and append /chat/completions themselves; others want the full request URL. If both sides add /chat/completions, requests go to /chat/completions/chat/completions and return 404 — on a 404, check for a doubled path first. Only Bilibili Index-Translate states a Base URL in its claim steps (index-translate.bilibili.com/v1, model Index-Translate-35B-A3B); every other offer’s Base URL and model ID are unstated — check the official page.

What does the 50,000 hits/day cap mean?

A hit is every request for a website file, not a visit: a page with 2 CSS + 3 JS + 5 images produces 11 hits on one load (InfinityFree official KB example). InfinityFree caps hits at 50,000 per day; over the cap, the account goes offline for 24 hours. “Unlimited bandwidth” does not mean unlimited visits. HelioHost uses load units instead: 200 GB of memory/day + 10,000 CPU/day, sampled every 60 seconds.

Source: InfinityFree official forum KB and HelioHost Wiki; verified 2026-11-13.

Can a site run on a free subdomain?

Free subdomains cost nothing to start: InfinityFree (25+ suffixes), Byet.host (24 suffixes), x10Hosting (4 suffixes), GoogieHost (suffixes written three ways), ProFreeHost (free subdomain). An owned domain stays under its owner’s control and can move. FreeHosting.com requires an owned domain and hosts no free subdomains. Cloudflare cannot be used on InfinityFree free subdomains, but can be used on an owned domain (forum guide).
