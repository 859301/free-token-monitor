What do RPM, RPD, and TPM mean? When do quotas reset?

RPM = requests per minute; RPD = requests per day; TPM = tokens per minute. Some vendors also limit TPD (tokens per day). All four axes apply at once — hitting any one returns a 429. Verified examples: Groq is “per model 30 RPM / 1,000 requests per day / 200K tokens per day”; OpenRouter free models are “20 RPM / 50 requests per day”; Gemini free tier is “5–30 RPM / per-model daily caps”. Reset times differ per vendor: Cloudflare Workers AI resets at 00:00 UTC (08:00 Beijing time); Huawei Cloud CodeArts at 24:00 (UTC+8); AMD at 00:00 Beijing time; IFM at 00:00 UTC. See each offer’s “reset” field.

Source: verified listings; verification dates 2026-10-09–2026-11-08.

What happens when I hit a limit or a trial ends? Will I be charged?

It depends on the vendor — three patterns exist. Stops: Tencent Cloud TokenHub notes usage stops without auto-charging — postpaid billing must be enabled to continue. Switches to pay-as-you-go: Alibaba Cloud Bailian switches by default — turn on “stop when exhausted”; Qiniu also switches to pay-as-you-go when used up. Overage billing: You.com bills overage at $5 per 1,000 searches. Where this site’s data doesn’t state what happens, confirm on the official page before claiming: is a card required, is there a “stop when exhausted” switch, does anything auto-renew? Never assume “free allowance” means no charge.

Source: verified risk and reset fields; verification dates 2026-10-27–2026-11-01.

I got a 429 error. Should I wait a minute or until tomorrow?

Check which limit you hit. Minute-level limits (RPM/TPM): wait a bit and retry. Day-level limits (RPD/TPD): wait until the reset time. Some vendors send a Retry-After header (suggested wait in seconds) — follow it. Don’t retry blindly: OpenRouter explicitly notes that failed requests also count toward the daily cap, so retrying burns the daily allowance faster. Day-level waits depend on each vendor’s reset time (see the previous question). Longer-term relief: lower concurrency, exponential backoff, and spreading requests across vendors (without violating vendor terms).

Source: verified listings, including the OpenRouter risk note, verified 2026-10-27.

Is the free web chat the same as the free API allowance?

No — they are two separate systems. Free web/app chat and open-platform API allowances don’t share quotas, may list different models, and bill independently. Web free doesn’t mean API free, and vice versa. For example, community-compiled Q&A notes that DeepSeek’s free web version doesn’t mean the API is free, and Gemini’s app/web version and API free tier are separate. Judge only by the platform’s API allowance wording. This site tags every offer by access type: API, client app, or web/cloud.

Source: community-compiled Q&A; verified access-type fields.

Why can’t some free models plug straight into Codex CLI or Claude Code?

The most common cause is a protocol mismatch. Different tools require different protocols: Claude Code requires the Anthropic protocol; Codex CLI requires the Responses API; Cline, OpenCode, and similar tools mostly use OpenAI-compatible formats. A free key that only offers OpenAI Chat Completions format can’t plug directly into a tool requiring another protocol. The second common cause is a model that doesn’t support function calling, which coding tools rely on. The third is a wrong Base URL — for example, adding /chat/completions twice, which returns a 404. Configuration details are per each tool’s official docs; this site’s listings mark which offers are OpenAI-compatible (23 of 43).

Source: research notes; verified OpenAI-compatibility fields.

How do I fill in the Base URL? Do I need to add /chat/completions?

There is no single answer — it depends on the tool. Some tools want the Base URL ending at /v1 and append /chat/completions themselves; others want the full request URL. If both sides add /chat/completions, requests go to /chat/completions/chat/completions and return 404 — on a 404, check for a doubled path first. In this site’s data, only Bilibili Index-Translate states a Base URL in its claim steps (index-translate.bilibili.com/v1, model Index-Translate-35B-A3B); every other offer’s Base URL and model ID are unstated — check the official page.

Source: verified data; Bilibili Index-Translate listing, verified 2026-11-03.

Is Oracle Cloud Always Free really free forever?

There is no fixed end date while the account stays active — but “forever” comes with rules. The A1 allowance is 2 OCPU / 12 GB since June 2026 (the 4 OCPU / 24 GB in old tutorials is outdated; the PAYG 4-core-free claim is disputed). Idle instances may be reclaimed under the 7-day rule; capacity errors are common; there is no SLA; and the $300 trial credit is separate (30 days). Details: Oracle Always Free detail page.

Source: Oracle official docs, verified 2026-11-12.

Why do I get “Out of host capacity” for VM.Standard.A1.Flex?

Your home region temporarily has no Always Free capacity for that shape. The official guidance: switch availability domain, wait and retry, or upgrade to PAYG for more compute (Always Free resources still cost nothing after upgrading — only usage above the free limits is billed). The official FAQ says adding capacity may take several days. The AMD-based E2.1.Micro is an alternative shape.

Source: Oracle official docs and FAQ, verified 2026-11-12.

Will Oracle reclaim my idle Always Free instance?

Yes, it can be reclaimed. The official docs’ test: over 7 days, CPU 95th-percentile utilization below 20%, network utilization below 20%, and memory utilization below 20% (A1 shapes only) counts as idle. Accounts idle for more than 30 days may also be treated as abandoned and suspended or terminated. Don’t fake real usage with load scripts.

Source: Oracle official docs, verified 2026-11-12.

Is AWS Free Tier still 12 months free?

No. New accounts moved to the $200 credit / 6-month model (from July 15, 2025, per second-hand sources’ date; the official FAQ describes only the credit model): $100 on signup + up to $100 more for exploring foundational services, with no fixed free EC2 VM, and it cannot be extended. When the free plan expires, the account is suspended and data is kept 90 days, then permanently deleted if not upgraded. Note: the official FAQ gives two wordings for credit expiry — 6 months and 12 months — so go by the official page and billing page. Most new customers need no payment method to register.

Source: AWS official FAQ, verified 2026-11-12.

Annual or monthly — which costs less over 3 years?

With stated renewal prices, annual wins; with unstated renewal, the 3-year total is unknowable. Calculated by this site from stated prices: RackNerd 1 GB at $21.99/year × 3 = $65.97 (same-rate renewal stated in the official FAQ); DigitalOcean Basic 512MiB at the $4.00/month cap × 36 = $144.00 (list price, monthly cap). HostEONS is excluded from the math — its renewal price is unstated, so no 3-year total can be computed. Monthly billing buys flexibility (cancel any time); annual billing buys the lower total where renewal is stated.
