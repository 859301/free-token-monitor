Dual-license structure

Main license: ISC License, Copyright (c) 2026 Lucide Icons and Contributors, granting “use, copy, modify, and/or distribute this software for any purpose with or without fee”, with the condition that the copyright and license notices appear in all copies.

The license page names a set of icons derived from the Feather project (the full set is given on the full license page); that set uses the MIT License, Copyright (c) 2013-present Cole Bemis, with the condition that the copyright and permission notices be included in all copies or substantial portions of the software. Both licenses are permissive, but notice retention must cover both parts.

Free scope and paywall boundary

The license page and LICENSE file mention no paid tier — check the official page. The license page gives no icon count — not verified. The license page states no geographic restriction.

Prohibited uses

Neither the ISC nor the MIT text states a ban on resale or trademark use — check the official page. Brand icons are not addressed on the license page — check the official page.

Notice retention and attribution

The duty is retention of copyright and license notices with copies (notices in source code and distributed artifacts, not on-screen attribution). For Feather-derived icons, the MIT notices must be retained as well.

FAQ

Can Lucide icons be used commercially?

Yes. The ISC text grants use, copy, modify, and distribute rights for any purpose with or without fee; the license page states no separate commercial restriction.

Is on-screen attribution needed?

No visible on-screen attribution is needed. The duty is retention of copyright and license notices with copies, covering both the ISC and MIT parts.

What is different about Feather-derived icons?

That set uses the MIT license rather than ISC; the list follows the full license page. Notice retention applies as well: notices must be included in all copies or substantial portions of the software.
