Iconify (icon aggregator)

Published 2026-11-15 · Updated 2026-11-15 · Source: Iconify repository collections.md · Verified 2026-11-14

Icon aggregatorCheck per setNo unified license

Iconify is an aggregation catalog and distribution tool for icon sets, not a single-license icon library. The collections.md file gives the author, icon count, license, and license URL for each set, and licenses differ across sets — check per set. Conclusions here rest only on the first 631 lines of collections.md read (4,882 lines total). Verified 2026-11-14; check the official page.

No unified license — check per set: no single license can be written as the Iconify license. Commercial use, attribution, modification, and redistribution have no unified answers; check the license and license URL of each set.

How to check

  1. Find the set containing the icon in collections.md.
  2. Read the license marking and license URL for that set.
  3. Follow the attribution or notice retention duties in that set license text.
  4. When switching to icons from another set, check that set license again.

Catalog markings do not replace upstream license texts; upstream LICENSE files for Tabler, Material Symbols, and others were not read in full — check the official page.

FAQ

Can all icons on Iconify be used commercially?

There is no unified answer. Iconify is an aggregation catalog and distribution tool; licenses differ across sets, so check the license and license URL of each set.

How is one set license checked?

Find the set in collections.md, read its license marking and license URL, then follow the attribution or notice retention duties in that set license text; check again when switching sets.

Can catalog icon counts be quoted directly?

Catalog figures follow the catalog. Lucide, for example, is cataloged as 2,052 icons; whether that matches the Lucide official figure is not verified.
