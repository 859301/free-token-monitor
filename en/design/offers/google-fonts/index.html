Google Fonts (font library)

Published 2026-11-15 · Updated 2026-11-15 · Source: Google Fonts official FAQ · Verified 2026-11-14

Font libraryOFLApacheCommercial useLogo useCheck per font

The Google Fonts FAQ states that all fonts are open source and without cost, usable in commercial products and even included in commercial products for sale; licenses differ per font (most commonly the SIL Open Font License, some under the Apache license or the Ubuntu Font License) — check each font; the FAQ expressly states that Google Fonts can be used within any logo. Check per font: Google Fonts has no single whole-library license; licenses differ per font, so check the license of each font in use. OFL restrictions must not be written as whole-library restrictions.

Check per font: licenses differ

The FAQ states: conditions for use and redistribution are set by each font license; the most common is the SIL Open Font License, with some fonts under the Apache license or the Ubuntu Font License. Google Sans and Google Sans Flex were for Google use only before November 2025 and now use the SIL Open Font License. Product Sans is not available; Google owns the font, for Google products only.

The Noto collection covers 1,000+ languages and 150+ writing systems (Noto collection figures, not whole-library figures). The FAQ gives no total font count — not verified.

Free scope and paywall boundary

The FAQ mentions no paid tier — check the official page. Fonts can be used on print, websites, apps, teaching materials, ebooks, storefronts, jewelry, and any surface. With self-hosting, Google receives no visitor data (a dedicated FAQ section; technical note).

Prohibited uses

The FAQ does not directly state a ban on reselling font files themselves; that restriction comes from the OFL text and must not be written as a whole-library Google Fonts restriction. Use of a font in logo text does not equal trademark registration — check the official page.

Notice retention and attribution

The full FAQ text mentions no attribution requirement — check each license text. Notice requirements in each font license text follow that license text.

FAQ

Can Google Fonts be used commercially?

Yes. The FAQ states fonts can be used in commercial products and even included in commercial products for sale; conditions are set by each font license, so check each font.

Can Google Fonts be used in a logo?

Yes. The FAQ expressly states Google Fonts can be used within any logo. Use in logo text does not equal trademark registration.

Do all fonts share one license?

No. Licenses differ per font: most commonly the SIL Open Font License, some under the Apache license or the Ubuntu Font License — check each font.
