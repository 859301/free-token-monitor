Per-item check notes

Google Fonts licenses differ per font — check each font. Iconify licenses differ per set — check the license and license URL of each set. Figma Community licenses vary by resource type and free/paid status, and creators can add or replace terms — check the license marking on each resource page. These three entries show only “Check per item” in the table, with no unified conclusion.

Other notes

Official license page information could not be confirmed for Unsplash, Pixabay, Alibaba PuHuiTi, other Chinese fonts and icon libraries, sites such as Freepik and Flaticon, and Simple Icons — check the official page; design tools such as Canva and Penpot are outside the scope of asset collections.
