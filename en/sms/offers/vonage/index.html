Trial mode and limits

A new account starts in trial mode, sending messages and calls only to at most 5 verified test numbers (the registered number plus 4 verified test numbers). Trial SMS carries a *[FREE SMS DEMO, TEST MESSAGE]* label; topping up and upgrading removes the limits; trial credit cannot buy virtual numbers. Neither the pricing overview page nor the two support articles state a trial amount or validity — check the official page.

SMS and Verify prices

The SMS API starts at €0.00735 / $0.00860 per message (US LVN); the Messages API starts at €0.00110 / $0.00129 per message. The Verify API costs €0.05200 / $0.06084 per successful verification, plus message and voice rates.

Conflicting wording, shown side by side

  • USD price difference: the Vonage Philippines regional site and staging copy of the same overview page show the SMS API from €0.00735 / $0.00809, while the production page shows $0.00860; the EUR price matches and the USD price differs, a difference from exchange-rate timing; this page follows the production page and notes the difference.
