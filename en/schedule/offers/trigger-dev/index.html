How the $5 credits are spent

Billing is per second of execution plus a $0.000025 invocation cost per run. Machine prices: Micro $0.0000169 per second, Small 1x (default) $0.0000338 per second, Small 2x $0.0000675 per second, Medium 1x $0.0000850 per second, Medium 2x $0.0001700 per second, Large 1x $0.0003400 per second, Large 2x $0.0006800 per second.

Official example: a 10-second task running 100 times a day on Small 1x costs about $1.09 a month. A slow task costs more than a fast one, and a larger machine costs more per second.

Waits not billed, concurrency rules

Waiting for subtasks is checkpointed and not billed; wait.for and wait.until past 5 seconds are checkpointed and not billed. Concurrency limits apply only while code is executing, so waiting runs do not occupy concurrency slots.

Runs in the DEV environment are not charged; billing covers production task execution only.

Run duration and rate limits

Runs have no maximum duration; maxDuration is configurable, or timeout.None for indefinite runs. The API rate limit is 1,500 requests per minute on all plans, and batchTrigger() takes up to 1,000 tasks per call.

Overage and paid tiers

Once the credits are used, upgrading is required to keep running tasks (pricing page FAQ). Paid tiers: Hobby $10/month ($10 credits included); Pro $50/month ($50 credits included); on paid plans, compute past the included credits is billed at compute usage rates.
