How executions are counted

One execution is one function run or one step execution: a run with five steps uses six executions. How many function runs 50,000 executions a month covers depends on the step count per run.

The 500,000 events a month and 10,000 scores a month are separate monthly allowances; queue depth is 100,000, and the maximum event size is 256 KiB.

Cron and delays

Cron expressions have five fields, use UTC by default, and accept a TZ= prefix for timezones. Schedule firing carries jitter from 1 second to 5 minutes; on daylight saving change days a schedule may run zero, one, or two times, and Inngest does not correct for daylight saving time. Each function allows up to 10 triggers.

One sleep lasts up to 1 year, but total sleep within a run on the Free plan is capped at 30 days; maximum run length is 30 days, including sleeps.

Step and run ceilings

One step lasts up to 2 hours and returns up to 4 MiB; one function holds up to 1,000 steps, and one run holds up to 32 MiB of state. The 2-hour ceiling does not extend a shorter host timeout.

On the Free plan, a function is paused automatically after 20 consecutive failures.

Overage and paid tiers

Overage behavior is not stated on the official pages read — check the official page. Paid tiers: Pro from $99/month (1m executions a month included, then $50 per 1m); Business from $499/month (10m executions a month included, then $25 per 1m).

FAQ

How many function runs do 50,000 executions cover?

The step count per run decides. One execution is one function run or one step execution, so a run with five steps uses six executions.

Can a Free plan function be paused for failures?

Yes. On the Free plan, a function is paused automatically after 20 consecutive failures.

How long can one step run?

One step lasts up to 2 hours, and one run lasts up to 30 days, including sleeps. The 2-hour ceiling does not extend a shorter host timeout.
