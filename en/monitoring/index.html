Monitoring & analytics: 6 free tiers and 1 30-day trial

Updated 2026-11-14 · 7 entries (verified 2026-11-13) · Specs and terms transcribed from vendor official pages

6 free tiers: UptimeRobot (uptime monitoring), Sentry Developer (error tracking), Umami Hobby, PostHog, Microsoft Clarity, Google Analytics 4 Standard (analytics). 1 trial: Plausible (30-day free trial, no permanent free plan on the cloud). Self-hosted monitoring software (Uptime Kuma, UptimeFlare, Nezha Monitoring) is not a hosted allowance; parameters follow each project’s page.

Monitoring & analytics covers three kinds of tools for watching a live service: uptime monitoring (alerts when a site goes down), error tracking (locating code errors), and analytics (traffic and user behavior). Unlike deploy platforms that run a service (see Deploy &amp; hosting), monitoring tools are usually metered by monitor count, event count, and retention period.
