How the labels work

Every deal uses the same labels, to avoid vague wording:

  • Status: live / live (no end date stated) / disputed / historical archive / unverified.
  • Renewal label: same-rate renewal stated / first-term price only / not stated. Credit-type entries have no “renewal” — only expiry rules.
  • Task burden: none / click to renew / daily check-in / must post / points-based / disputed (conflicting accounts stated).
  • Data and continuity risk: low (listed cloud vendor) / medium (budget host, back up) / high (task host, unverified terms, or exit signals), with the reason stated.
  • Promo-code dependence: no code / get the code on the official page / third-party code (unverified).
