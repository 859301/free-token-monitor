Object storage: 1 free tier, 1 pay-as-you-go service, and 2 database-bundled storage notes

Updated 2026-11-14 · 2 entries (verified 2026-11-13) · Specs and terms transcribed from vendor official pages

1 free tier: Cloudflare R2 (monthly 10 GB-month storage, 1M Class A operations, 10M Class B operations, egress free). 1 pay-as-you-go service: Backblaze B2 (storage $6.95/TB/30 days, egress free up to 3x average monthly stored data, $0.01/GB beyond that, no free tier). 2 database-bundled storage notes: Supabase Storage (1 GB file storage, provided with the Supabase plan) and Firebase Storage (the Spark plan column reads “Not applicable”; free allowances sit in the Blaze column), with details on the Supabase and Firebase detail pages.

Object storage holds user-uploaded images, files, and similar content. Egress charges are the main difference between providers: R2 charges no egress for any storage class, while B2 bills egress under the 3x rule — see Egress rules compared. Database-bundled storage is covered in the section below, with details on the database detail pages.
