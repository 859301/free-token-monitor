Cloudflare R2 free tier

Cloudflare · Verified 2026-11-13 · Page updated 2026-11-14

Free tier Metered monthly Egress free Infrequent Access excluded from the free tier

Cloudflare R2 free tier, metered monthly: each month 10 GB-month storage, 1M Class A operations, 10M Class B operations, egress free. Beyond the free allowance, standard storage costs $0.015/GB-month, Class A operations $4.50/M requests, Class B operations $0.36/M requests. The Infrequent Access storage class is excluded from the free tier, priced separately, with a 30-day minimum storage period. No egress bandwidth charges apply to any storage class. Verified 2026-11-13 — check the official page before claiming.

FAQ

What does the R2 free tier include each month?

How is R2 charged beyond the free allowance?

Standard storage $0.015/GB-month, Class A operations $4.50/M requests, Class B operations $0.36/M requests. Egress is free of charge. Verified 2026-11-13.
