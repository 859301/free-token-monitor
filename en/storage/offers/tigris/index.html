What the free tier includes

The free-tier block on the official pricing page is headed “Every month, on every account” and states: “No card to start. The allowance below resets monthly and applies before anything is metered.” Each month includes: 5 GB Standard storage, 10,000 PUT, COPY, POST and LIST requests, 100,000 GET, SELECT and other requests. Below the pricing table, the page also states: “First 5 GB of Standard storage free. First 10,000 Class A and 100,000 Class B requests free.” The free allowance applies to Standard storage only.

The pricing page states that Tigris pricing is the same across all geographies. Data retrieval applies only to the Infrequent Access and Archive Instant Retrieval tiers.

Storage classes

Standard: $0.02/GB/month; Class A requests $0.005/1,000; Class B requests $0.0005/1,000; data retrieval free; no minimum storage retention. The free allowance applies to Standard storage only.

Infrequent Access: $0.01/GB/month; Class A $0.005/1,000; Class B $0.0005/1,000; data retrieval $0.01/GB; 30-day minimum storage. Objects deleted, updated, or transitioned to another tier before 30 days still incur a 30-day storage charge; objects stored for 30 days or longer are charged only for the actual number of days stored.

Archive: $0.004/GB/month; Class A $0.005/1,000; Class B $0.0005/1,000; data retrieval free; 90-day minimum storage. Data in the Archive tier requires restoration before it can be accessed; during restoration the data is moved to the Standard tier and charged at the Standard storage rate, then moved back to the Archive tier once the restoration period is over.

Archive Instant Retrieval: $0.004/GB/month; Class A $0.005/1,000; Class B $0.0005/1,000; data retrieval $0.03/GB; 90-day minimum storage.

Egress rule

The official pricing page states: “Other clouds charge for every gigabyte that leaves. Tigris does not.” The Egress row of the pricing table reads Free for all four storage classes. For the egress comparison, see Free-tier egress rules compared.

Request classes

The pricing page FAQ lists the operations in each request class. Class A: CreateBucket, CreateMultipartUpload, CopyObject, ListObjects, ListObjectsV2, ListMultipartUploads, ListBuckets, ListParts, PutBucketCors, PutBucketLifecycleConfiguration, PutObjectTagging, PutObjectAcl, PutObjectRetention, PutObjectLegalHold, PutObjectLockConfiguration, PutBucketAcl, PutBucketPolicy, PutBucketTagging, PutBucketAccelerateConfiguration, PutBucketOwnershipControls, PutObject. Class B: GetBucketAccelerateConfiguration, GetBucketAcl, GetBucketCors, GetBucketLifecycleConfiguration, GetBucketLocation, GetBucketOwnershipControls, GetBucketPolicy, GetBucketPolicyStatus, GetBucketRequestPayment, GetBucketTagging, GetBucketVersioning, GetObject, GetObjectAcl, GetObjectTagging, HeadBucket, HeadObject. All DELETE and CANCEL requests are free.

Wordings shown side by side: the free-tier block on the pricing page reads PUT, COPY, POST and LIST / GET, SELECT and all other requests, while the official documentation partner integrations page groups them as PUT, POST, LIST / GET, HEAD. Both wordings are shown; check the official page.
