Deploy & hosting: 7 free tiers, 1 trial, and 2 no-free-tier notes

Updated 2026-11-14 · 10 entries (verified 2026-11-13) · Specs and terms transcribed from vendor official pages

7 free tiers: Vercel Hobby, Netlify Free, Cloudflare Workers, Cloudflare Pages, Render free tier, Northflank Sandbox, EdgeOne Free Plan. 1 trial: Railway (30 days, $5 credits). 2 with no free tier: Fly.io ($1/7-day trial, bills under $5 waived), Koyeb (pricing page shows only three plans from Pro $29/month). Permanence, card requirements, and overage behavior differ across the free tiers — the tables below state each one.

Deploy & hosting means running a website or backend service on a managed platform, with the platform handling servers and the runtime environment. That differs from a VPS, where the environment is installed and maintained by hand (see Free VPS), and from PHP + MySQL shared hosting.

Services not in the list, and why

The following services or claims did not have verifiable official-page terms when checked, so no verified entry is shown for them. They are named here to explain why — not as recommendations.

  • GitHub Pages: figures came from a second-hand check citing GitHub Docs (2026-09 to 2026-10-30), with no direct verification against an official page in this round. The one sentence confirmed on the GitHub Student Pack official page: “Get one site per GitHub account and organization, and unlimited project sites.”
  • Heroku: the free tier was removed on 2022-11-28; now Eco from $5/month (multiple second-hand sources agree); moved to sustaining engineering in 2026-02.
  • Free shared hosting: the PHP + MySQL form, separate from deploy and hosting.
  • Free VPS and VPS deals: the server form — see Free VPS and VPS Deals.
  • Cloudflare R2: object storage, outside the scope of deploy and hosting.
  • Self-hosted software (Coolify, Uptime Kuma, PocketBase): the software itself is not a hosting allowance.
