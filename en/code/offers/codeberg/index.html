Scope

The FAQ states that Codeberg is run by a non-profit association with a mission of advancing free content and free/open-source software, and that public works need a suitable license. Codeberg does not offer private hosting services; commercial projects needing private repositories are pointed to self-hosted Forgejo, the Git hosting software Codeberg runs.

Repositories and storage

The default limit is 100 repositories per user or organization, with increases granted on request. The FAQ states there is no intention to monetize through limits and quotas, and no quota for valid use cases; requests are needed above 750 MiB of Git storage, 1.5 GiB of packages, LFS, and attachments, or generally large CI resources. Codeberg reserves the right to deny service when resource usage is unreasonable or affects other users.

Private content

The FAQ states that contributors to free/libre software projects may keep up to 100 MB of private content for personal notes, side projects, or anything kept private, and that private content strictly required for a free/libre software project (team-internal discussions, security patch preparation, time-limited release preparation) is tolerated; requests are needed above 100 MB. The requests page states private repositories are limited to 100 MiB per user, with no exceptions for proprietary software. Both unit wordings are presented side by side — check the official page.

CI

Forgejo Actions default runners can be used by anyone with no permission request; dedicated runners are available on request when the default offer is not enough. Woodpecker CI requires access granted per account, with rules including clearly free-licensed code, a publicly accessible repository, a brief project purpose in the README or repository description, and reasonable resource usage.

Funding and membership

The FAQ states that Codeberg is powered by donations and membership fees of the non-profit association, that membership is completely optional, that no payment is required for any specific service, and that no payments are accepted for exceptions to the rules.

Unconfirmed information

Monthly CI minute figures, data transfer allowances, and user limits are not stated on the official pages read — check the official page.
