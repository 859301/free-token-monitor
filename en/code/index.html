Code hosting & CI: GitHub Free and GitLab Free free tiers compared

Updated 2026-11-14 · 2 entries (verified 2026-11-13) · Specs and terms transcribed from vendor official pages

2 free tiers: GitHub Free ($0: unlimited public/private repositories, 2,000 CI/CD minutes/month, 500 MB Packages storage, Issues & Projects, Dependabot, community support, Codespaces access) and GitLab Free ($0: 5 users per top-level group, 400 compute minutes/month, 10 GiB adjustable storage, 5 GiB data transfer per month, sign-up needs no credit card). CI minutes follow each plan’s own metering, so the figures cannot be equated directly — see CI minutes compared. Several GitHub Free features in the comparison table are limited to public repositories, and GitLab Free shared runners require card verification; see each detail page.

Code hosting means keeping code repositories on a hosted platform, with version control, issues, and CI/CD (automatic builds and tests after a commit). Running a website and backend on a platform is a deploy service — see Deploy & hosting — and running a self-installed environment is a VPS — see Free VPS.

Services not in the tables above, and why

The following services are not in the tables above, with the reason for each stated as a fact.

  • GitHub Pages: a static hosting service, outside the code hosting scope; figures come from second-hand checks citing GitHub Docs (2026-09 to 2026-10-30), with no direct verification on an official page.
  • GitHub Student Developer Pack: an eligibility-based resource requiring student status verification, including GitHub Pro free during enrollment; outside the free-tier scope.
  • Buying, selling, or applying for student pack accounts on behalf of others: a violation of platform terms, with accounts easily banned.
  • Deploy services: running a website and backend on a platform belongs to deploy and hosting — see Deploy & hosting.
  • Servers and web hosting: server options — see Free VPS. PHP + MySQL web hosting is a separate stage with its own terms.
