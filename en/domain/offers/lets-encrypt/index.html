Let's Encrypt free DV certificates

Let's Encrypt · Verified 2026-11-13 · Page updated 2026-11-14

Free DV certificates ACME Rate limits

Let's Encrypt issues free DV certificates, requested through the ACME process. The rate limits on the official rate limits documentation page: 50 certificates/registered domain/7 days, 5 certificates with the same identifier set/7 days, 5 failed validations/account/hostname/hour, 300 new orders/account/3 hours, up to 100 identifiers per certificate; ARI renewals are exempt from all rate limits. Certificate validity — check the official page. Verified 2026-11-13.

ARI renewals

The official rate limits documentation states that ARI renewals are exempt from all rate limits. Renewal processes and ACME client settings — check the official page.

Unconfirmed information

Certificate validity: check the official page. The claim that certificate validity is transitioning from 90 days to 64 days and then 45 days is a second-hand claim, not confirmed on the rate limits documentation page. The rate limits documentation page itself does not literally write “free”; the “free DV certificates” wording follows the widely known fact beyond that page.

How to apply

  1. Confirm the domain resolves to the server
  2. Request a certificate with an ACME client
  3. Renew before expiry (ARI renewals are exempt from all rate limits). Specific clients and commands — check the official page.
