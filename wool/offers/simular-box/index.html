Simular Box 是什么

box by Simular 是一台云端 Linux 桌面，给 AI Agent 用的：把它作为远程 MCP 服务器接入 Claude、ChatGPT、Claude Code、Codex、Cursor、OpenCode、Hermes、OpenClaw、VS Code 或 DeepSeek Harness，Agent 就能用一台真实电脑——打开浏览器、点击、输入、看屏幕、跑命令。多个 Agent 共享同一台 box、同一份文件与登录状态。box 闲置时休眠，Agent 连接时唤醒。

它不是传统 VPS：没有 24/7 不间断运行的承诺，不能当普通服务器挂机；访问方式是 MCP，不是 SSH 直连一台通用主机。
