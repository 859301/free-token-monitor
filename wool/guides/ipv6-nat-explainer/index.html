IPv6 Only 与 NAT 主机：能干什么、不能干什么

本页更新于 2026-11-13

IPv6-only 主机没有公网 IPv4，只能被 IPv6 访问、但能主动访问 IPv4 与 IPv6；NAT 主机共享一个公网 IPv4，靠端口转发对外提供服务。两者都能跑 Agent、出站访问、反向代理后的服务；都不能直接被 IPv4 用户访问、不能直接建站直连。买之前先看套餐表的 IP 列：写「IPv6 only」「NAT IPv4」「共享 IP」的，就是这两类。

本指南是概念科普，不含厂商推荐。Hax 等 IPv6/NAT 主机未核实到当前条款；InstaBox 的网关访问作已核实的接入方式例子。

什么是 IPv6-only

IPv6-only 主机只有 IPv6 地址，没有公网 IPv4。它能主动访问互联网（IPv4 与 IPv6 都能出站），但只有 IPv6 用户能直接访问它。国内很多网络仍以 IPv4 为主，IPv6-only 主机上的服务，IPv4 用户打不开——除非前面加一层反向代理或 CDN。

什么是 NAT 主机

NAT 主机与多台机器共享一个公网 IPv4，每台机器分到一部分端口（比如 10000–11000）。对外提供服务时，要用分配到的端口、通过端口转发访问；不能用 80/443 等标准端口直接建站。NAT 主机的价格通常更低，因为 IPv4 地址是稀缺资源。

能干什么

  • 跑 Agent、爬虫、定时任务（出站访问不受限）。
  • 反向代理/CDN 后的服务（Cloudflare Tunnel 等）。
  • 学习、实验、练手。
  • InstaBox 的例子：官方文档写明通过端口发布获得公开 HTTPS 链接——网关访问模式，不依赖独立入站 IPv4。

不能干什么

  • 直接被 IPv4 用户访问（IPv6-only）。
  • 用标准端口直接建站（NAT）。
  • 需要固定 IPv4 的场景（某些 API 白名单、游戏服务器、语音服务）。

怎么判断

看套餐表的 IP 列：写「IPv6 only」「NAT」「Shared IPv4」「共享 IP」的，就是这两类；写「1 × IPv4」「Dedicated IPv4」的，才是独立 IPv4。买之前先确认——价格再便宜，IP 类型不对也白搭。

常见问题

IPv6-only 主机能建站吗？

能，但要加反向代理/CDN 让 IPv4 用户访问；直接建站只有 IPv6 用户能打开。

NAT 主机值得买吗？

出站场景（Agent、爬虫、任务）值得；对外服务场景先确认端口分配规则与限制。
