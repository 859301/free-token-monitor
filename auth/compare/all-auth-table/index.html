口径说明

Clerk 的 MRU：用户在注册 24 小时后回访即计为 retained。Auth0 的 MAU：官网表述为 “External Active Users”（外部活跃用户）。Descope 的 MAU：1 个月内注册或登录的用户。Frontegg 的 MAU：日历月内至少登录一次的用户。WorkOS 的活跃用户：日历月内执行任一用户操作的用户。Logto 除 MAU 外还计 token，仅 access token 计入。Stytch 的月活用户与 agent 判定细节、Supabase Auth 与 Firebase Auth 的 MAU 判定细节以官方页面为准。口径不同，数字不能直接比大小，完整对照见MRU 与 MAU 有什么不同。
