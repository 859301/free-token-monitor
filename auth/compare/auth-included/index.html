归属不同

Clerk 与 Auth0 是独立认证服务，免费档只针对认证本身。Supabase Auth 与 Firebase Auth 是数据库免费档的一部分：Supabase Auth 随 Supabase 免费档提供，Firebase Auth 随 Firebase 免费额度提供。附带认证的绑卡、超限、暂停等规则与各自数据库免费档的规则在同一详情页里，见数据库板块详情页。

口径说明

Clerk 用 MRU：用户在注册 24 小时后回访即计为 retained。Auth0、Supabase、Firebase 用 MAU：Auth0 的表述为 “External Active Users”（外部活跃用户）。MAU 的判定细节在各家官网已读页面中未述，以官方页面为准。口径不同，数字不能直接比大小，完整对照见MRU 与 MAU 有什么不同。

怎么选

已经用 Supabase 或 Firebase 做数据库的，附带认证额度随数据库免费档提供，数字见上表，完整规格见数据库板块详情页。只需要认证、不需要数据库的，看独立认证服务的免费档：Clerk Hobby 与 Auth0 Free 的逐项对照见Clerk vs Auth0。

常见问题

Supabase Auth 和 Firebase Auth 有单独的详情页吗？

没有单独的认证详情页。Supabase Auth 随 Supabase 免费档提供，Firebase Auth 随 Firebase 免费额度提供，完整规格在数据库板块的 Supabase 与 Firebase 详情页里。核实于 2026-11-13。

4 家的认证额度数字能直接比大小吗？

不能。Clerk 用 MRU（留存用户），其余三家用 MAU，口径不同。MAU 的判定细节在各家官网已读页面中未述，以官方页面为准。核实于 2026-11-13。
