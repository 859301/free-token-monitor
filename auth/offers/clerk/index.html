MRU 与 MRO 的定义

MRU（monthly retained user，每月留存用户）：用户在注册 24 小时后回访即计为 retained。官网原文：“A user is counted as retained when they return 24+ hours after signing up.”MRO（monthly retained org，每月留存组织）：组织至少 2 名成员，且至少 1 名为当月 retained 用户。MRU 与 MAU 的口径对照见MRU 与 MAU 有什么不同。
