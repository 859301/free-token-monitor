活跃用户与连接的定义

官网 FAQ 写明：用户在日历月内执行任一用户操作（例如注册、登录、个人资料更新）即计为活跃（“A user is considered active if they perform any user action (for example: sign up, sign in, or profile update) within the calendar month”）。连接的定义：WorkOS 与任一组终端用户之间的关系，每个用 SSO 或 Directory Sync 的企业客户计为 1 个连接（“Each enterprise customer you support with SSO or Directory Sync is counted as one connection”）。
