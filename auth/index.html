不在列表中的服务及原因

以下服务不在上面的列表里，原因按事实列出。

  • Neon 认证（Managed Better Auth）：认证额度随 Neon 数据库免费档提供（60k MAU/项目），详情见数据库板块Neon 详情页。
  • GitHub Student Pack 里的 Clerk Pro：在读学生身份的优惠，与面向所有人的 Hobby 免费档不同。
  • PocketBase：自托管软件，不是托管认证服务；自托管路线见数据库板块自托管 vs 托管数据库。
  • PropelAuth：官方定价页在本次核实中未能直接读到文本，二手说法互相冲突（有的写 10,000 MAU 免费档，有的写无免费档），不在上面的列表里。
  • AWS Cognito：免费额度随账号与用户池的新旧、档位（Lite/Essentials/Plus）不同，本次未核实，不在上面的列表里。
  • 自托管软件（Keycloak、SuperTokens、FusionAuth 等）：自托管软件，不是托管认证服务；自托管路线见SSO/SCIM 连接怎么计数中的自托管路线一节。
