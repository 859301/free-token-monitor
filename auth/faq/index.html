中文问题

登录注册自己写还是用 Clerk/Auth0？

自己写登录注册需要自行实现注册、登录、会话、密码重置等环节；用认证服务按各家免费档来：Clerk Hobby 50,000 MRUs/应用，Auth0 Free 至多 25,000 MAU。完整对照见认证选型对照。

Clerk 免费版够多少用户？

50,000 MRUs/应用、100 MROs/应用，无限应用。MRU 的定义：用户在注册 24 小时后回访即计为 retained。详情见Clerk Hobby 详情页。

Auth0 免费版够多少用户？

至多 25,000 MAU，官网表述为 External Active Users（外部活跃用户）。定价页 FAQ 确认 25,000 阈值。详情见Auth0 Free 详情页。

MRU 是怎么算的？

用户在注册 24 小时后回访即计为 retained。官网原文：A user is counted as retained when they return 24+ hours after signing up. 完整口径对照见MRU 与 MAU 有什么不同。

MRO 是什么？

MRO（每月留存组织）：组织至少 2 名成员，且至少 1 名为当月 retained 用户。Clerk Hobby 每应用 100 MROs，超 100 MRO 须升级 B2B 附加项。

Clerk 免费版要绑信用卡吗？

不用。官网写明 “No credit card required”（无需信用卡）。详情见Clerk Hobby 详情页。

Auth0 注册要绑信用卡吗？自定义域名呢？

注册无需绑卡；1 个自定义域名需绑卡验证。详情见Auth0 Free 详情页。

Clerk 免费版能接几个社交登录？

至多 3 个。通用配置步骤见社交登录基础。

Auth0 免费版有几个企业连接和组织？

1 个企业连接、5 个组织。另有 1,000 个 M2M token、5 个 Actions、1 天日志保留，无 Pro MFA / 角色管理。详情见Auth0 Free 详情页。

超过 50,000 MRU 会怎样？

须升级 Pro；超 100 MRO 须升级 B2B 附加项；FAQ 写明 1 个月宽限期。Pro $20/月（年付），含 50,000 MRUs，超出 $0.02/个。完整对照见认证额度超了怎么办。

超过 25,000 MAU 会怎样？

Auth0 超限后的行为在官网已读页面中未述，以官方页面为准。付费档为 Essentials $35/月、Professional $240/月。完整对照见认证额度超了怎么办。

Supabase Auth 与 Firebase Auth 的认证额度是多少？

Supabase Auth 50,000 MAU，随 Supabase 免费档提供；Firebase Auth 50K MAU，随 Firebase 免费额度提供。详情见数据库板块的Supabase 详情页与Firebase 详情页。

Clerk 和 Auth0 的免费档日志保留多久？

都是 1 天。Clerk Hobby 与 Auth0 Free 的日志保留均为 1 天，见Clerk 详情页与Auth0 详情页。

Stytch 免费额度是多少？

10,000 月活用户与 AI agent、无限组织、5 个 SSO 或 SCIM 连接、1,000 个 M2M token；超出 5 个的连接每个 $125；绑卡要求以官方页面为准。核实于 2026-11-14。

Descope 免费档超限会怎样？

无超额计费，超过 7,500 MAU、10 个租户或 3 个 SSO 连接中的任一上限都须升级 Pro；超 MAU 或租户上限后会收到警告邮件与升级宽限期，宽限期时长以官方页面为准。核实于 2026-11-14。

WorkOS 免费额度是多少？SSO 免费吗？

用户管理至多 1,000,000 MAU 免费，每多 1,000,000 用户 $2,500/月；SSO 与 Directory Sync 不含免费连接，官方博客写各 $125/连接/月；开始免费，生产环境需加信用卡。核实于 2026-11-14。

Logto 免费档包括什么？

至多 50,000 MAU、50K tokens（仅 access token 计入）、3 个应用、1 个 M2M 应用、1 个自定义域名、3 个社交连接、1 个 webhook、3 天审计日志保留，无需信用卡；无组织、MFA、企业 SSO。核实于 2026-11-14。

Kinde 免费档包括什么？超出会怎样？

10,500 MAU、5 个月活组织、1 个企业 SSO 连接、2,000 个 M2M token、MFA、自定义域名，无需信用卡；超出包含额度后按已公布费率自动计费，Free 档超出单价以官方页面为准。核实于 2026-11-14。

Frontegg 的企业连接怎么计数？

SSO 与 SCIM 分开计数，同一客户同时用两项计 2 个连接；按量付费计划含 5 个合计、7,500 MAU、无限组织、自定义域名，开始不需要信用卡。核实于 2026-11-14。

哪些免费档含 MFA 和自定义域名？

MFA：Descope、Kinde、WorkOS 含，Logto 为 Pro 附加项，Auth0 无 Pro MFA。自定义域名：Clerk、Kinde、Logto、Frontegg 含，Auth0 含 1 个、需绑卡验证，Descope 从 Pro 起，WorkOS 需额外月费。新 6 条核实于 2026-11-14，Clerk 与 Auth0 核实于 2026-11-13。
