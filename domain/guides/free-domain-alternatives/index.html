免费域名现状与替代

核实于 2026-11-13 · 本页更新于 2026-11-13

免费域名现状：Freenom 免费已死，2026 年恢复的是付费销售。替代路线有三条：is-a.dev 免费子域名（$0，部分信息未确认）、低价 .com（首年 $9.48–$12.08 促销价，续费 $10.68–$19.98，按注册商不同）、学生包域名（须验证学生身份）。eu.org、JS.ORG、DigitalPlat 官网条款未确认。

现状

Freenom 免费域名已死：2023 年停新注册，2024 年退出域名业务，2026-07-23 恢复付费销售 .tk / .cf / .gq。时间线见Freenom 免费域名已死。目前没有经官网确认的免费顶级域名注册渠道。

三条替代路线

免费子域名：is-a.dev 提供免费 .is-a.dev 子域名，新推 .is-a.bot，通过 GitHub 仓库 is-a-dev/register 按指引注册；申请资格与审核时长在官网已读页面中未渲染，续期规则未述，以官方页面为准。

低价 .com：Spaceship 首年 $9.48（促销价，标价 $10.38）、续费 $10.68；Porkbun 注册/续费/转入均为 $11.81，含 ICANN 费；Namecheap 首年 $12.08（促销价，标价 $15.98）、续费 $19.98。首年价与续费价分开看，见注册商价格对照。

学生包域名：GitHub Student Developer Pack 官网页列出 Namecheap .me 域名 1 年 + SSL 证书 1 年、Name.com 25+ 后缀免费域名、.TECH 标准域名 1 年，须验证学生身份。见学生身份的域名优惠。

免费子域名与自有域名的区别

免费子域名归项目域名之下，存续取决于项目方；自有域名自己控制，主机换了域名还能用，但域名过期未续费会被收回。重要站点用自有域名。虚拟主机自带免费子域名的情况见免费子域名 vs 自有域名（虚拟主机指南）。

官网条款未确认的选项

eu.org、JS.ORG、DigitalPlat FreeDomain 仅见二手说法，厂商官网当前条款未确认，不在对照表里。DigitalPlat 一源提醒旧 Telegram 频道被劫持、只信 GitHub/控制台。

确认清单

  1. 确认首年价与续费价：促销价不等于续费价。
  2. 确认 ICANN 费的收法：含在价格内，还是购买时另计。
  3. 确认子域名的控制权与续期规则：免费子域名的续期规则以官方页面为准。
  4. 确认学生优惠的年限：学生包域名优惠为 1 年期，1 年后以官方页面为准。
