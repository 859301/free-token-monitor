中文问题

域名哪里买最便宜？

三家注册商的 .com 价格（核实于 2026-11-13）：Spaceship 首年 $9.48（促销价，标价 $10.38）、续费 $10.68；Porkbun 注册/续费/转入均为 $11.81，含 ICANN 费；Namecheap 首年 $12.08（促销价，标价 $15.98）、续费 $19.98。首年价最低与续费价最低的都是 Spaceship。首年价与续费价分开看，见注册商价格对照。

还有免费域名吗？Freenom 免费域名还能注册吗？

没有。Freenom 免费域名已死：2023 年停新注册，2024 年退出域名业务，2026-07-23 恢复付费销售 .tk / .cf / .gq。替代路线：is-a.dev 免费子域名、低价 .com、学生包域名，见免费域名现状与替代。

.com 续费多少钱？

续费价（核实于 2026-11-13）：Spaceship $10.68，Porkbun $11.81，Namecheap $19.98。续费价与首年价不同：Spaceship 首年 $9.48（促销价），Namecheap 首年 $12.08（促销价），Porkbun 三项同价 $11.81。见注册商价格对照。

首年价和续费价为什么不一样？

首年价常为促销价，续费按续费价计。Namecheap 首年 $12.08 为 25% off 促销价（标价 $15.98），续费 $19.98；Spaceship 首年 $9.48 为促销价（标价 $10.38），续费 $10.68；Porkbun 三项同价，均为 $11.81。见首年价与续费价。

ICANN 费是什么？三家注册商怎么收？

ICANN 费是 ICANN 收取的费用，三家收法不同：Porkbun 含在价格内（All prices include ICANN and any other fees）；Namecheap $0.20/次，在购买时加到标价上（部分域名适用）；Spaceship $0.20/年，购买时强制收取。

域名隐私保护要钱吗？

Namecheap：符合条件的域名终身免费。Spaceship：免费（符合条件的域名）。Porkbun：官网已读页面未述，以官方页面为准。

转入域名多少钱？

转入价（核实于 2026-11-13）：Porkbun $11.81，Namecheap $12.28（促销价，标价 $15.98），Spaceship $10.18（促销价，标价 $10.68）。转入价与续费价不同，分开看。

Cloudflare 免费计划包括什么？

Free 计划 $0 包括 DNS、Unmetered DDoS Protection、CDN、Universal SSL、Free Managed Ruleset、WAF，官网 plans 页定位为个人/业余项目。Pro $20/月（年付）或 $25/月（月付），Business $200/月（年付）或 $250/月（月付）。Registrar 为成本价注册、无加价，.com 具体价格在 plans 页未给出数字。见Cloudflare 详情页。

Let's Encrypt 证书有什么限流？

50 证/注册域/7 天、5 张相同标识集/7 天、5 次验证失败/账户/主机名/小时、300 新订单/账户/3 小时、每证至多 100 标识；ARI 续期免于全部限流。证书有效期以官方页面为准。见Let's Encrypt 限流详解。

is-a.dev 免费子域名怎么申请？有什么不确定的？

通过 GitHub 仓库 is-a-dev/register 按指引注册；官网称免费服务并将保持，新推 .is-a.bot 子域名。申请资格与审核时长在官网已读页面中未渲染，续期规则未述，以官方页面为准。见is-a.dev 详情页。

eu.org、JS.ORG、DigitalPlat 还能申请免费子域名吗？

三者仅见二手说法，厂商官网当前条款未确认：eu.org 二手说法称人工审核、数天至数周/数月、需真实姓名地址；DigitalPlat 二手说法称默认 1 年、可免费续期、无 SLA，一源提醒旧 Telegram 频道被劫持、只信 GitHub/控制台；JS.ORG 仅见二手说法提及存在。以官方页面为准。

学生能免费拿到域名吗？

GitHub Student Developer Pack 官网页列出：Namecheap .me 域名 1 年 + 1 张 SSL 证书 1 年、Name.com 25+ 后缀免费域名、.TECH 标准域名 1 年免费；须验证学生身份。1 年后的续费价以官方页面为准。见学生身份的域名优惠。

免费子域名和自己买的 .com 有什么区别？

免费子域名归项目域名之下，存续取决于项目方；自有域名自己控制，主机换了域名还能用，但域名过期未续费会被收回。见免费子域名与低价域名：三条路线。

域名、DNS、CDN、SSL 各是什么关系？

域名是名字，DNS 管解析，CDN 管分发与防护，SSL 管加密。Cloudflare Free 计划含 DNS、CDN、Universal SSL；Let's Encrypt 签发免费 DV 证书。见域名、DNS、CDN、SSL 各管什么。
