从零上线检查清单

按顺序过一遍，每项做完再往下走；跳过的项记下来，上线前补上。

立项与开发

  1. 写下一句话：解决谁的什么问题。见立项验证指南。
  2. 找几位潜在用户聊，问过去的行为，不问“会不会用”。
  3. 做一个着陆页或等候名单，看有没有人留联系方式。
  4. 定下最小可用的第一版范围：一个核心功能。
  5. 代码放进仓库，定好分支与部署方式。见代码托管列表。

部署与上线

  1. 选部署方式：托管免费层、虚拟主机还是 VPS。见部署与托管列表、免费虚拟主机列表、免费 VPS 列表。
  2. 选数据库，确认不活跃暂停与超额规则。见免费数据库列表与暂停与缩容说明。
  3. 定认证方式：自己写还是用托管认证。见认证列表。
  4. 域名、DNS、SSL 配好。见域名列表。
  5. 文件与图片存对象存储，不塞进代码仓库。见对象存储列表。

运营必需品

  1. 注册验证邮件与通知邮件接好。见邮件列表。
  2. 监控与告警：宕机提醒、错误追踪、访问分析。见监控分析列表。
  3. 定时任务与队列安排好。见周边能力指南。

变现与增长

  1. 收款方式：费率、税务代管、提现路径。见支付变现列表。
  2. 上线前检查：备份、账单提醒、状态页。见上线运营指南。

$0 组合：3 套搭配

以下 3 套搭配只用各列表页已经列出的条目组成，数字与规则见各自详情页，条款以厂商官方页为准。

组合一：Vercel + Supabase + R2

  • Vercel Hobby：100 GB Fast Data Transfer、1M CDN 请求、1M 函数调用、4 CPU 小时；达上限不可加购；仅限个人或非商业用途。
  • Supabase：500 MB 数据库、50,000 MAU、5 GB egress、1 GB 文件存储；免费项目 1 周不活跃暂停；至多 2 个活跃项目。
  • Cloudflare R2：每月 10 GB-month 存储、1M Class A 操作、10M Class B 操作，出站免费。
  • 可以再加：Resend（3,000 封/月、100 封/天）、Clerk（每个应用 50,000 MRUs）。

组合二：Cloudflare 全家桶

  • Cloudflare Workers：100,000 请求/天、每次调用 10 ms CPU；配套免费量含 KV 100,000 读/天、D1 5M 行读/天、Queues 10,000 ops/天。
  • Cloudflare Pages：500 构建/月、100 自定义域名/项目、20,000 文件/站。
  • Cloudflare R2：每月 10 GB-month 存储、1M Class A 操作、10M Class B 操作，出站免费。
  • Cloudflare Free 计划：$0，包括 DNS、CDN、Universal SSL。

组合三：VPS 自托管

  • Oracle Always Free：2 OCPU / 12 GB 内存、200 GB 块存储、每月 10 TB 出站流量；绑卡与回收规则见详情页。
  • 域名：域名列表里的注册商，首年价与续费价分开列出，对照见注册商对比。
  • Let's Encrypt：签发免费 DV 证书，通过 ACME 流程申请。
  • UptimeRobot：50 个监控器、5 分钟检测间隔、基础状态页，无需信用卡。
  • 自托管与托管路线的对照见托管免费层 vs VPS 自托管。
提醒：各条的绑卡要求、超额行为与暂停规则不同，搭配前看各自详情页；条款随时可能调整，以厂商官方页为准。
