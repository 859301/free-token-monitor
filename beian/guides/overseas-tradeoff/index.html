大陆服务器与境外服务器的取舍

指南 · 核实于 2026-11-14、2026-11-15

备案义务看服务器所在地：服务器位于中国大陆的，须通过接入商完成 ICP 备案；中国大陆以外（包括香港）的服务器不需要备案。域名解析到中国大陆服务器 IP 即产生备案义务。

内容以主管部门与接入商官方页面为准，个案以属地管局答复为准。

判断依据：服务器所在地与接入商

  • 服务器位于中国大陆的，必须通过接入商的平台完成 ICP 备案，否则网站可能被关停；中国大陆以外（包括香港）的服务器不需要备案（阿里云）。
  • 使用中国大陆境内服务器开办网站或 App，必须先办理 ICP 备案，拿到通信管理局下发的 ICP 备案号后才能开通访问（腾讯云）。
  • 域名解析到中国大陆服务器 IP 即产生备案义务，不因用途而改变：域名用于内网穿透、API 端点、邮件服务等非网站用途，解析到大陆服务器 IP 也须备案；域名仅有 MX 记录指向邮件服务器、不用于网站托管或任何 Web 服务时，不需要备案（阿里云）。
  • 使用非标准端口（80/443 以外）不改变备案义务（阿里云）。
  • 未在腾讯云提交过备案就把域名解析至腾讯云中国境内云服务，会被未备案监测系统识别并阻断访问、跳转到固定页面；HTTPS 访问同样会被拦截阻断（腾讯云）。

CDN 与回源规则（阿里云）

  • 域名托管在大陆服务器上，使用阿里云 CDN 分发内容时必须申请 ICP 备案，域名须有工信部 ICP 备案号（备案信息不要求登记在阿里云名下）。
  • 源站部署在阿里云时，回源域名须加入阿里云 ICP 备案系统，否则域名访问会被阻断。
  • 绑定自定义域名到 OSS、WAF、Anti-DDoS 代理 IP 时，同样要求域名完成 ICP 备案。

混合架构判断

源站与分发、回源链路涉及中国大陆服务器或大陆接入服务时，备案义务按接入商规则判断，以接入商官方页面与属地管局答复为准。

公安备案的海外服务器表述

阿里云中文版流程概述页写：海外服务器但境内可访问时，仍须办理公安备案。公安备案的办理时限与流程见 公安联网备案事实卡。
