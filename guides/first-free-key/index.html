领取第一个免费 Key 并完成第一次调用

本页更新于 2026-11-12

领取第一个免费 Key 只要四步：选一条不绑卡的额度 → 注册并完成实名（如需）→ 在控制台创建 API Key → 用 curl 或代码发第一次请求，再去控制台确认用量。零绑卡起步可选智谱 GLM Flash（长期免费层）或哔哩哔哩 Index-Translate（免注册免 Key，仅翻译场景）。

1. 选一条额度

第一次调用建议选「不绑卡、长期免费或每天重置」的额度，例如智谱 GLM Flash（长期免费层，注册即可调用）或哔哩哔哩 Index-Translate（免注册、免 Key，仅翻译场景）。选之前先看三点：门槛（要不要实名/绑卡）、节奏（长期/每天/一次性）、重置时间。对照表见 不绑卡的最佳免费大模型 API 对比。

2. 注册与实名

按额度页的领取步骤注册账号；有的额度要求手机号或实名认证（见每条的「门槛」字段），按厂商官方页的流程完成。不要用多账号、虚假身份等违反厂商条款的方式领取。

3. 创建 API Key

登录厂商控制台，找到 API Key / 密钥管理入口创建一把 Key，复制保存好（很多厂商只显示一次）。入口位置与 Key 的权限设置以厂商官方文档为准。Key 不要发到公开场合，不要提交到公开仓库。

4. 第一次调用：零 Key 示例

下面是哔哩哔哩 Index-Translate 的调用示例：领取步骤写明「免注册直接调用」「按 OpenAI 格式把 Base URL 指向 index-translate.bilibili.com/v1，模型名 Index-Translate-35B-A3B，不带 Key 也能调」。注意 Index-Translate 是翻译模型，适合翻译场景，不是通用对话模型。

curl -X POST "https://index-translate.bilibili.com/v1/chat/completions" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Index-Translate-35B-A3B",
    "messages": [{"role": "user", "content": "把 hello 翻译成中文"}]
  }'

上面是 OpenAI 兼容格式的通用写法；/chat/completions 是 OpenAI 兼容接口的常规路径，具体以厂商文档为准。如果返回 404，先检查路径是否重复加了两次（见 常见问题 Q6）。

5. 第一次调用：需要 Key 的额度

以智谱 GLM Flash 为例：注册账号后在开放平台创建 API Key，模型名填 glm-4.5-flash 或 glm-4.7-flash（见额度页的领取步骤），Base URL 以智谱官方文档为准，请求头里带上 Key。其他额度的 Base URL 与模型 ID 未注明，以厂商官方页面为准。

6. 查用量与限额

调用成功后，去厂商控制台的用量/限额面板确认：额度是否到账、用了多少、限速是多少、重置时间是什么时候。如果额度没到账，先看领取步骤里有没有签到、绑定、实名等前置条件没完成。

7. 出错了怎么办

401、402、429 各自的排查方法见指南 401 / 402 / 429 报错排查；想把 Key 接入编程工具见指南 把免费 Key 接入 Claude Code / Codex / Cline / OpenCode。

提醒：各厂商的控制台入口、Key 创建位置、Base URL 与模型 ID 以厂商官方文档为准；各工具的配置方式以各工具官方文档为准。请遵守厂商条款，不要绕过地区或支付规则。
