部署与托管：7 个免费层、1 个试用与 2 个无免费层说明

本页更新于 2026-11-13 · 10 条（核实于 2026-11-13）· 规格与条款照录厂商官方页

7 个免费层：Vercel Hobby、Netlify Free、Cloudflare Workers、Cloudflare Pages、Render 免费层、Northflank Sandbox、EdgeOne 免费计划。1 个试用：Railway（30 天、$5 credits）。2 个无免费层：Fly.io（$1/7 天试用、账单低于 $5 豁免）、Koyeb（定价页只有 Pro $29/月起的三个计划）。免费层的永久性、绑卡要求与超额行为各不相同，见各条详情页。

部署与托管指把网站与后端服务放到托管平台上运行，由平台处理服务器与运行环境；与需要自己装环境、自己运维的 VPS 不同（见免费 VPS 列表），与 PHP + MySQL 的虚拟主机也不同（见免费虚拟主机列表）。两条路线的对照见托管免费层 vs VPS 自托管。

不在列表中的服务及原因

以下服务不在上面的列表里，原因按事实列出。

  • GitHub Pages：参数来自援引 GitHub Docs 的二手核查（2026-09 至 2026-10-30），本次未做官网页面直接核实。GitHub Student Pack 官网页确认的一句为：“Get one site per GitHub account and organization, and unlimited project sites.”
  • Heroku：免费 tier 已于 2022-11-28 移除，现 Eco $5/月起（多源二手说法一致）；2026-02 转 sustaining engineering。
  • 免费虚拟主机：PHP + MySQL 形态，见免费虚拟主机列表。
  • 免费 VPS 与 VPS 羊毛：服务器形态，见免费 VPS 列表与羊毛 VPS 列表。
  • Cloudflare R2：对象存储，不在部署与托管列表范围内。
  • 自托管软件（Coolify、Uptime Kuma、PocketBase）：软件本身不是托管额度；自托管路线见托管免费层 vs VPS 自托管。
