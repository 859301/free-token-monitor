不租服务器怎么部署

核实于 2026-11-13 · 本页更新于 2026-11-13

三条路线：静态托管（Vercel Hobby、Netlify Free、Cloudflare Pages）、边缘计算与 CDN（Cloudflare Workers、EdgeOne）、容器与后端（Render、Northflank、Railway 试用、Fly.io、Koyeb）。每条路线的免费量、休眠、绑卡、商用限制各不相同，见各条详情页。

本页内容
  • 路线一：静态托管
  • 路线二：边缘计算与 CDN
  • 路线三：容器与后端
  • 何时需要服务器
  • 选路线前看清的限制

路线一：静态托管

Vercel Hobby：100 GB Fast Data Transfer、1M CDN 请求、1M 函数调用、4 CPU 小时，达上限不可加购，仅限个人非商业用途。Netlify Free：每月 300 credits，生产部署 15 credits/次。Cloudflare Pages：500 构建/月、1 并发构建、20,000 文件/站、单文件 25 MiB。

路线二：边缘计算与 CDN

Cloudflare Workers：100,000 请求/天、每次调用 10 ms CPU，KV、D1、Queues、Logs 各有免费量。EdgeOne 免费计划：$0/月、不限量安全流量/请求、不限量边缘函数请求、不限量免费 SSL，有限内测中、无 SLA、仅限标准 Web 内容；EdgeOne 提供 CDN、DDoS 防护、WAF 等边缘安全能力。

路线三：容器与后端

Render 免费层：免费 Web Service、Key Value、Postgres，15 分钟无流量 spin down。Northflank Sandbox：2 服务、2 任务、1 数据库，常开不休眠，必须绑卡。Railway：30 天试用、$5 credits，试用后 $1/月起并缩减。Fly.io：无免费层，$1/7 天试用、账单低于 $5 豁免。Koyeb：无免费层，Pro $29/月起。

何时需要服务器

需要自己装环境、自己运维，或需要 root 权限的，见免费 VPS 列表。需要 PHP + MySQL、装 WordPress 的，见免费虚拟主机列表。托管与自托管的对照见托管免费层 vs VPS 自托管。

选路线前看清的限制

构建与文件：Pages 500 构建/月、20,000 文件；Netlify 生产部署 15 credits/次。休眠：Render 15 分钟 spin down，Northflank 常开。商用：Vercel Hobby 仅限个人非商业用途。绑卡：Northflank 必须绑卡，Render $1 验证，EdgeOne 无需信用卡，Railway 可无卡试用，其余官网未述。超额：见免费额度超了怎么办。
