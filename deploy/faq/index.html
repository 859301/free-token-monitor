中文问题

推荐一下大伙用过的免费好用的服务

这是 V2EX 帖子标题原话。部署与托管：7 个免费层（Vercel Hobby、Netlify Free、Cloudflare Workers、Cloudflare Pages、Render、Northflank Sandbox、EdgeOne），Railway 为 30 天试用，Fly.io 与 Koyeb 没有免费层。免费虚拟主机见免费虚拟主机列表，免费 VPS 见免费 VPS 列表。

不租服务器部署混合搜索引擎

这是 V2EX 帖子标题原话。不租服务器的路线有三条：静态托管、边缘计算与 CDN、容器与后端，各条限制见不租服务器怎么部署。

Vercel 免费版能商用吗？超了会怎样？

不能。服务条款 §4 写明 Hobby 计划只能用于个人或非商业用途，公平使用两列清单见Vercel Hobby 商业限制说明。超了：官网定价页写明免费 Hobby 账户受用量上限约束、不能购买额外用量；Hobby 文档页写明超限后 30 天等待期。详情见Vercel Hobby 详情页。

免费实例会休眠吗？

Render 免费实例 15 分钟无入站流量后 spin down，唤醒约 1 分钟；Northflank Sandbox 常开不休眠。其余服务的休眠政策在官网已读页面中未述。完整对照见免费实例休眠与冷启动。

Render 免费 Postgres 多久过期？

创建后 30 天到期；到期后 14 天宽限期，之后连数据一起删除。每个工作区 1 个，1 GB。详情见Render 详情页。

Railway 试用结束后会怎样？

试用后 $1/月起，缩减为 1 个项目/3 个服务、0 个自定义域名，每服务至多 1 vCPU / 0.5 GB RAM。试用为一次性 $5 额度、30 天过期。详情见Railway 详情页。

Fly.io 还有免费额度吗？

没有免费层。官网定价文档写明“Is there a free tier? No.”只有 $1/7 天试用与个人组织月账单低于 $5 的豁免。详情见Fly.io 详情页。

Koyeb 还有免费层吗？

没有。定价页只列 Pro、Scale、Enterprise 三个计划，整页无 Starter/免费计划。详情见Koyeb 详情页。

部署服务需要绑信用卡吗？

逐家不同：Northflank 必须添加支付方式；Render $1 验证扣款（退还）；EdgeOne 无需信用卡；Railway 可无卡试用；Fly.io 试用开始无需绑卡、之后需要；Vercel、Netlify、Workers、Pages、Koyeb 在官网已读页面中未述。完整对照见部署服务要绑卡吗。

Netlify 的 credits 怎么算？

Free 计划每月 300 credits，官网写 $0 forever。生产部署 15 credits/次、计算 10 credits/GB-hour、带宽 20 credits/GB、Web 请求 2 credits/10K。详情见Netlify 详情页。

Cloudflare Workers 和 Pages 有什么区别？

计量口径不同：Workers 按请求与 CPU 计量，Pages 按构建与文件设限。完整对照见Cloudflare Workers vs Pages。

EdgeOne 免费计划有什么限制？

有限内测中、无 SLA、仅限标准 Web 内容（不含视频/大文件分发）；配额见EdgeOne 详情页。用量不限量、无超额费用；可接入站点数量在官方页面中未确认。

Heroku 免费层还在吗？

不在。Heroku 免费 tier 已于 2022-11-28 移除，现 Eco $5/月起；2026-02 转 sustaining engineering。见部署与托管列表页末尾的说明框。

GitHub Pages 为什么不在列表里？

GitHub Pages 的参数来自援引 GitHub Docs 的二手核查（2026-09 至 2026-10-30），本次未做官网页面直接核实。见部署与托管列表页末尾的说明框。

部署在这些平台上，国内访问快吗？

没有速度实测数据。各家官网页未述国内访问速度，以官方页面为准。
