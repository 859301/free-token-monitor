中文问题

用户上传的图片/文件存哪？

这是调研中的归纳问法。对象存储用来存放用户上传的图片、文件等内容：Cloudflare R2 每月免费层、Backblaze B2 按量付费，数据库附带的 Supabase Storage 与 Firebase Storage 见数据库板块。出站规则见出站规则对照。

R2 和 B2 哪个免费额度大？

B2 没有免费层，无法按免费额度比较。R2 每月免费：10 GB-month 存储、1M Class A 操作、10M Class B 操作，出站免费。详情见R2 vs B2 对照。

出站流量（egress）收费吗？

R2 不收费：所有存储类均不收出站带宽费用。B2 直接出站每月平均存储量 3 倍以内免费、超出 $0.01/GB，经合作 CDN 出站不限量免费。完整对照见出站规则对照。

R2 免费层每月包含什么？

每月 10 GB-month 存储、1M Class A 操作、10M Class B 操作，出站免费。官方定价页写明全部包含用量按月计量。详情见Cloudflare R2 详情页。

R2 超出免费额度后怎么收费？

标准存储 $0.015/GB-month，Class A 操作 $4.50/M 请求，Class B 操作 $0.36/M 请求。出站不收费。详情见Cloudflare R2 详情页。

R2 免费层适用于 Infrequent Access 吗？

不适用。官方定价页计费示例中，Infrequent Access 的免费层一栏为 NA。Infrequent Access 价格：$0.01/GB-month，Class A $9.00/M，Class B $0.90/M，数据取回 $0.01/GB，最短存储 30 天。见R2 存储类别指南。

Infrequent Access 的最短存储期是多久？

30 天。未满 30 天删除或转出时的计费，以官方页面为准。见R2 存储类别指南。

R2 的 Class A 和 Class B 操作怎么区分？

官方已读页面未述两类操作各包含哪些操作，以官方页面为准。两类操作的免费量与价格：免费层每月 1M Class A、10M Class B；超出后 Class A $4.50/M 请求，Class B $0.36/M 请求。

Backblaze B2 有免费层吗？

没有。官方定价页两次抓取均未出现“10GB 免费”表述。B2 按量付费：存储 $6.95/TB/30 天。详情见Backblaze B2 详情页。

B2 存储和出站分别多少钱？

存储 $6.95/TB/30 天。出站每月平均存储量 3 倍以内免费，超出 $0.01/GB；经合作 CDN 出站不限量免费。Overdrive $15/TB/月。详情见Backblaze B2 详情页。

哪些合作 CDN 走 B2 出站免费？

Fastly、Cloudflare、bunny.net、CacheFly、CoreWeave、Equinix Metal、Vultr、phoenixNAP。经这些合作 CDN 出站不限量免费。见对象存储与 CDN 指南。

Supabase Storage 包含多少文件存储？

1 GB 文件存储，随 Supabase 套餐提供。详情见数据库板块 Supabase 详情页。

Firebase Storage 的免费额度在哪个计划列？

定价页 Spark 计划列为“Not applicable”，免费额度在 Blaze 列。详情见数据库板块 Firebase 详情页。

Free object storage with free egress?

这是调研中的归纳问法（英文）。Cloudflare R2：每月免费层（10 GB-month 存储、1M Class A 操作、10M Class B 操作），所有存储类出站不收费。Backblaze B2 没有免费层，出站按 3 倍规则计费。详情见出站规则对照。
