R2：所有存储类出站不收费

官方定价页写明：“There are no charges for egress bandwidth for any storage class.”（所有存储类均不收出站带宽费用。）Standard 与 Infrequent Access 出站均不收费。详情见Cloudflare R2 详情页。

B2：3 倍规则

B2 直接出站每月平均存储量 3 倍以内免费，超出部分 $0.01/GB。平均存储量的计算方式以官方页面为准。详情见Backblaze B2 详情页。

B2：合作 CDN 出站不限量免费

经以下合作 CDN 出站不限量免费：Fastly、Cloudflare、bunny.net、CacheFly、CoreWeave、Equinix Metal、Vultr、phoenixNAP。合作 CDN 名单以官方页面为准。

出站费用怎么看

对照三点：出站是否收费、免费部分按什么计量、超出后单价。R2 出站不收费；B2 直接出站免费部分按每月平均存储量 3 倍计量，超出后 $0.01/GB；B2 经合作 CDN 出站不限量免费。

常见问题

出站流量是什么意思？

出站（egress）指数据从存储服务向外传出时产生的流量。出站规则：R2 不收费，B2 按 3 倍规则或合作 CDN 规则计费。核实于 2026-11-13。

B2 存得越多，出站免费量是不是越大？

B2 的免费出站量按每月平均存储量的 3 倍计量。平均存储量的计算方式以官方页面为准。核实于 2026-11-13。
