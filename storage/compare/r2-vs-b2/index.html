Cloudflare R2 vs Backblaze B2

核实于 2026-11-13 · 本页更新于 2026-11-13

R2 有按月计量的免费层，出站不收费；B2 按量付费，没有免费层，出站按 3 倍规则计费。存储价：R2 标准存储 $0.015/GB-month，B2 $6.95/TB/30 天。出站规则是两家的主要区别，见下表。

免费层与按量付费

R2 免费层按月计量：每月 10 GB-month 存储、1M Class A 操作、10M Class B 操作，出站免费。B2 没有免费层：官方定价页两次抓取均未出现“10GB 免费”表述，存储与出站按量计费。

出站规则

R2 所有存储类均不收出站带宽费用。B2 直接出站每月平均存储量 3 倍以内免费，超出部分 $0.01/GB；经合作 CDN（Fastly、Cloudflare、bunny.net、CacheFly、CoreWeave、Equinix Metal、Vultr、phoenixNAP）出站不限量免费。完整对照见出站规则对照。

存储类别与 Overdrive

R2 有 Standard 与 Infrequent Access 两个存储类别：Infrequent Access $0.01/GB-month、取回 $0.01/GB、最短存储 30 天，免费层不适用。B2 的 Overdrive 价格为 $15/TB/月，除价格外的条款以官方页面为准。

怎么选

需要每月免费额度与出站不收费的，对照 R2 的免费内容与价格。接受按量付费、对照合作 CDN 出站规则的，对照 B2 的价格与出站规则。数据库附带的存储见独立存储 vs 数据库附带存储对照。

常见问题

R2 和 B2 哪个免费额度大？

B2 没有免费层，无法按免费额度比较。R2 每月免费：10 GB-month 存储、1M Class A 操作、10M Class B 操作，出站免费。核实于 2026-11-13。

两家出站收费有什么不同？

R2 所有存储类出站均不收费。B2 直接出站每月平均存储量 3 倍以内免费、超出 $0.01/GB，经合作 CDN 出站不限量免费。核实于 2026-11-13。

B2 的 10 GB 免费说法是真的吗？

官方定价页两次抓取均未出现“10GB 免费”表述。B2 按量付费，没有免费层。核实于 2026-11-13。
