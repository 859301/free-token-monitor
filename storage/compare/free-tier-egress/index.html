出站免费的两家

R2：官方定价页写明，所有存储类均不收出站带宽费用。Tigris：官方定价页写明，其他云按每 GB 出站收费，Tigris 不收；定价表四个存储类的 Egress 一行均为 Free。两家详情见Cloudflare R2 详情页与Tigris 详情页。

有免费出站额度的

Google Cloud Storage：每月 100 GB 自北美至各区域目的地的出站数据传输免费，不含中国与澳大利亚目的地；免费层仅适用于 us-east1、us-west1、us-central1 三个区域的用量。超出后通用数据传输起价 $0.08/GiB。详情见Google Cloud Storage 详情页。

出站计费未述的

UploadThing：官方已读页面未述上传/下载计费，以官方页面为准。详情见UploadThing 详情页。

按量付费的参照

B2 没有免费层，按量付费。直接出站每月平均存储量 3 倍以内免费，超出部分 $0.01/GB；经 8 家合作 CDN 出站不限量免费。完整对照见对象存储出站规则对照。

R2 与 Tigris：全部存储类出站均免费。R2 核实于 2026-11-13，Tigris 核实于 2026-11-14。

每月 100 GB，仅自北美至各区域目的地，不含中国与澳大利亚目的地；免费层仅适用于 us-east1、us-west1、us-central1 三个区域的用量。超出后通用数据传输起价 $0.08/GiB。核实于 2026-11-14。

UploadThing 出站收费吗？

官方已读页面未述上传/下载计费，以官方页面为准。核实于 2026-11-14。
