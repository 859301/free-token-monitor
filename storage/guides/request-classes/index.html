操作次数计费：Class A / Class B 对照

R2 与 B2 核实于 2026-11-13；Tigris 与 Google Cloud Storage 核实于 2026-11-14 · 本页更新于 2026-11-14

R2

免费层：每月 1M Class A 操作、10M Class B 操作。超出后：Class A $4.50/M 请求，Class B $0.36/M 请求。两类操作各包含哪些操作，官方已读页面未述，以官方页面为准。详情见R2 详情页。

Tigris

免费额度：每月 10,000 次 PUT、COPY、POST 与 LIST 请求，100,000 次 GET、SELECT 及其他请求。超出后：Class A $0.005/1,000 次请求，Class B $0.0005/1,000 次请求；全部 DELETE 与 CANCEL 请求免费。定价页 FAQ 列出两类请求包含的操作：Class A 包含 CreateBucket、CreateMultipartUpload、CopyObject、ListObjects、ListObjectsV2、ListMultipartUploads、ListBuckets、ListParts、PutBucketCors、PutBucketLifecycleConfiguration、PutObjectTagging、PutObjectAcl、PutObjectRetention、PutObjectLegalHold、PutObjectLockConfiguration、PutBucketAcl、PutBucketPolicy、PutBucketTagging、PutBucketAccelerateConfiguration、PutBucketOwnershipControls、PutObject；Class B 包含 GetBucketAccelerateConfiguration、GetBucketAcl、GetBucketCors、GetBucketLifecycleConfiguration、GetBucketLocation、GetBucketOwnershipControls、GetBucketPolicy、GetBucketPolicyStatus、GetBucketRequestPayment、GetBucketTagging、GetBucketVersioning、GetObject、GetObjectAcl、GetObjectTagging、HeadBucket、HeadObject。详情见Tigris 详情页。

Google Cloud Storage

免费层：每月 5,000 次 Class A 操作、50,000 次 Class B 操作。超出后：产品页定价表的操作费起价 $0.0004/1,000 次操作；两类操作各包含哪些操作，官方已读页面未述，以官方页面为准。产品页定价表另写明免费操作不限量。详情见Google Cloud Storage 详情页。

免费操作

Tigris：全部 DELETE 与 CANCEL 请求免费。Google Cloud Storage：免费操作不限量。R2、B2 与 UploadThing 的免费操作在官方已读页面中未述，以官方页面为准。

对照清单

  1. 对照免费操作次数：R2 1M/10M，Tigris 10,000/100,000，Google Cloud Storage 5,000/50,000。
  2. 对照超出后单价：R2 Class A $4.50/M、Class B $0.36/M；Tigris $0.005/1,000 与 $0.0005/1,000；Google Cloud Storage 起价 $0.0004/1,000。
  3. 对照归类：Tigris 的归类见定价页 FAQ；R2 与 Google Cloud Storage 的归类在官方已读页面中未述。
  4. 对照免费操作：Tigris 的 DELETE 与 CANCEL 免费。
