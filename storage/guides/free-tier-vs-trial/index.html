免费档、试用与额度：怎么区分

R2 与 B2 核实于 2026-11-13；Tigris、Google Cloud Storage 与 Storj 核实于 2026-11-14 · 本页更新于 2026-11-14

免费档按月重置、没有结束日期；试用有固定天数、到期后按价计费或停用；额度是抵扣金、用完为止。三者写在同一页时容易混淆：Google Cloud 的免费档没有结束日期，$300 试用额度有效期 90 天；Storj 的免费是 30 天试用，不是按月重置的免费档。

免费档：按月重置

R2：每月 10 GB-month 存储、1M Class A 操作、10M Class B 操作，出站免费。Tigris：每月 5 GB 标准存储、10,000 次 PUT/COPY/POST/LIST 请求、100,000 次 GET/SELECT 及其他请求，出站免费，额度按月重置、开始无需绑卡。Google Cloud Storage：每月 5 GB-months 区域存储、5,000 次 Class A 操作、50,000 次 Class B 操作、100 GB 自北美出站，免费档没有结束日期，但 Google 保留提前 30 天通知后变更或取消的权利，未用额度不结转。详情见R2 详情页、Tigris 详情页与Google Cloud Storage 详情页。

试用：有固定天数

Google Cloud 试用：新客户获得 $300 欢迎额度，有效期 90 天；试用账户超出免费档的用量由 $300 额度支付，付费账户超出免费档的用量按标准费率计费；试用结束未升级为付费账户的，账户关闭、资源停用，30 天宽限期后永久删除。Storj 试用：官方定价页写明 30 天免费，Object Mount 一节写明 25 GB 免费存储 30 天、无需绑卡；试用结束后按标准价格计费：存储 $7/TB、出口 $7/TB，最短存储 30 天，最小对象 50KB。Storj 没有按月重置的免费档。

额度：抵扣金

Google Cloud 的 $300 是试用额度（抵扣金），与免费档是两回事：免费档是每月的免费量，额度是抵扣超出部分费用的金额，90 天有效期到了或用完了就结束。Storj 定价页写明每月 $5 最低费用不是使用额度（not a usage credit），试用期间免除。

最低消费

Storj：每月 $5 最低费用（以 USDC 支付除外，试用期间免除），不是使用额度。R2、Tigris、Google Cloud Storage 与 UploadThing 的最低消费在官方已读页面中未述，以官方页面为准。

对照清单

  1. 对照形态：免费档按月重置，试用有固定天数，额度是抵扣金。
  2. 对照结束日期：Google Cloud 免费档没有结束日期，$300 额度 90 天，Storj 试用 30 天。
  3. 对照到期后：试用结束是按价计费、停用，还是删除。
  4. 对照最低消费：Storj 每月 $5 最低费用不是使用额度。
  5. 在厂商官方页确认最终条款。
