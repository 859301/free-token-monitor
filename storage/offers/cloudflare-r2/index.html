常见问题

R2 免费层每月包含什么？

每月 10 GB-month 存储、1M Class A 操作、10M Class B 操作，出站免费。全部包含用量按月计量。核实于 2026-11-13。

R2 免费层适用于 Infrequent Access 吗？

不适用。官方定价页计费示例中，Infrequent Access 的免费层一栏为 NA。Infrequent Access 价格：$0.01/GB-month，Class A $9.00/M，Class B $0.90/M，数据取回 $0.01/GB，最短存储 30 天。核实于 2026-11-13。

R2 超出免费额度后怎么收费？

标准存储 $0.015/GB-month，Class A 操作 $4.50/M 请求，Class B 操作 $0.36/M 请求。出站不收费。核实于 2026-11-13。

R2 出站收费吗？

不收费。官方定价页写明，所有存储类均不收出站带宽费用。核实于 2026-11-13。
