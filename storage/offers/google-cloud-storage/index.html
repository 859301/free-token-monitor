Google Cloud Storage 免费层

Google Cloud · 核实于 2026-11-14 · 本页更新于 2026-11-14

免费层无结束日期仅三个美国区域需账单账号

Google Cloud Storage 免费层每月包含：5 GB-months 区域存储（仅美国区域）、5,000 次 Class A 操作、50,000 次 Class B 操作、100 GB 自北美出站数据传输（不含中国与澳大利亚目的地）。免费层仅适用于 us-east1、us-west1、us-central1 三个区域的用量，合并计算。免费层无结束日期，Google 保留提前 30 天通知后变更或取消的权利；未用额度不结转。使用免费层需要一个 Cloud Billing 账号。$300 试用额度 90 天有效，与免费层是两回事。核实于 2026-11-14，领取前请以厂商官方页为准。

免费层内容

官方免费层文档的 Cloud Storage 行写明：每月 5 GB-months 区域存储（仅美国区域，相当于 5 GB 数据存 1 个月）、5,000 次 Class A 操作、50,000 次 Class B 操作、100 GB 自北美至各区域目的地的出站数据传输（不含中国与澳大利亚）。官方产品页定价表另列：免费操作不限量，标准存储无取回费，入站数据传输不限量，同一位置内数据传输不限量。

适用区域

官方免费层文档写明：“The Free Tier benefits for Cloud Storage apply only to usage in the us-east1, us-west1, and us-central1 regions. Usage calculations are combined across these regions.”（Cloud Storage 免费层权益仅适用于 us-east1、us-west1、us-central1 三个区域的用量，用量合并计算。）三个区域以外的用量不在免费层内。

免费层与试用的区别

免费层与 $300 试用额度是两回事。免费层是每月额度，无结束日期；试用是给新用户的 $300 Welcome 额度，90 天有效。试用账单账户超出免费层限额时，由 $300 额度支付超额部分；付费账单账户超出免费层限额时，按标准费率计费。试用结束未升级为付费账单账户时，账单账户关闭、资源停止，30 天宽限期后永久删除。完整对照见免费档、试用与额度指南。

每月 100 GB 自北美至各区域目的地的出站数据传输免费，不含中国与澳大利亚目的地。入站数据传输不限量，同一位置内数据传输不限量。超出免费额度后，通用数据传输起价 $0.08/GiB。出站规则的完整对照见免费层出站规则对照。
