常见问题：免费 AI API 的 18 个问题

本页更新于 2026-11-12 · 共 18 个问题

以下问题按用户实际提问的措辞整理（含两条英文原问）。答案以额度数据为准；涉及未在官方页核实到的厂商的信息来自调研来源，已在答案中注明，领取前请以厂商官方页为准。

有哪些完全免费且无需绑定信用卡的 AI API？

按门槛字段，43 条额度里明确要求绑卡的只有 2 条：Cerebras（$5 免费额度）和 Vercel AI Gateway（每月 $5）；其余 41 条的门槛都不含绑卡。首页有「免绑卡」筛选，可以直接筛出这些额度。

但要注意两点：第一，「不需要绑卡」不等于「没有门槛」——很多额度要求注册账号、手机号或实名认证（见每条的「门槛」字段）。第二，个别厂商的注意事项里有例外，例如 Cloudflare Workers AI 的注意事项提到「部分新模型需要先绑付费方式」；领取前请在厂商官方页确认。

如果你的目标是「完全免费、长期可用」，先看 不绑卡的最佳免费大模型 API 对比 和 免费额度形态对比（长期免费层 vs 注册赠金 vs 周期重置）。

免费 AI API 的限速指标 RPM、RPD、TPM 分别代表什么？额度多久重置？

RPM（Requests Per Minute）是每分钟允许的请求数；RPD（Requests Per Day）是每天允许的请求数；TPM（Tokens Per Minute）是每分钟允许的 Token 数。有的厂商还按 TPD（每天 Token 数）限制。四个轴是同时生效的，撞上任何一个都会返回 429。

额度原文的例子：Groq 是「每模型 30 RPM / 1,000 次每天 / 20 万 Token 每天」；OpenRouter 免费模型是「20 RPM / 50 次每天」；Gemini 免费层是「5–30 RPM / 按模型限日额」。重置时间各家不同：Cloudflare Workers AI 在每天 00:00 UTC（北京时间 08:00）重置；华为云码道在每天 24:00（UTC+8）重置；AMD 在北京时间 0 点重置；IFM 在 UTC 0 点重置。具体见每条额度的「重置」字段。

遇到 429 时先判断撞的是分钟级还是日级限速：分钟级等一会儿再试，日级要等到重置时间。详见指南 401 / 402 / 429 报错排查。

免费额度到期/用完会扣钱吗？会不会自动转付费？

这取决于厂商，分三种形态，每条的「注意」事项和「重置」字段注明了已知情况：

  • 用完即停：例如腾讯云 TokenHub 的注意事项写明「用完不会自动扣费，需开通后付费才继续计费」。
  • 用完转按量计费：例如阿里云百炼的注意事项写明「用完默认转按量计费，记得开『用完即停』」；七牛云的注意事项写明「用完转按量计费」。
  • 超出后按量计费：例如 You.com 的注意事项写明「超出后按 $5/千次计费」。

未注明用完后处理方式的额度，领取前请在厂商官方页确认：是否需要绑卡、是否有「用完即停」类开关、额度过期后是否自动续费。不要假设「免费额度」一定不会扣钱。

官方网页版聊天免费与开放平台 API 免费额度是互通的吗？

不互通。网页版聊天（App / 官网对话框）的免费，与开放平台 API 的免费额度是两套体系：额度不共享，模型清单也可能不同，计费方式各自独立。网页版免费不等于 API 免费，反过来也一样。

例如社区整理的问答指出，DeepSeek 网页版的免费不等于 API 免费，API 侧的免费额度需要单独看开放平台的政策；Gemini 的 App/网页版与 API 免费层也是分开的。判断时以开放平台的 API 额度说明为准，不要拿网页版的免费体验推断 API。

额度分 API 直调、客户端、网页/云端三类，每条都标明了接入方式，领取前请确认「接入方式」是否为你需要的那种。

为什么部分免费模型无法直接接入 Codex CLI 或 Claude Code？

最常见的原因是协议不匹配。不同工具要求的协议不同：Claude Code 要求 Anthropic 协议；Codex CLI 要求 Responses API；Cline、OpenCode 等工具多用 OpenAI 兼容格式。一条只提供 OpenAI Chat Completions 格式的免费密钥，无法直接插进要求其他协议的工具。

第二个常见原因是模型不支持工具调用（function calling）。编程工具依赖工具调用来执行命令、读写文件；有的免费模型不支持或支持得不可靠，接上后会报错或行为异常。第三个原因是 Base URL 填错，例如把 /chat/completions 重复加了两次，导致 404。

具体排查步骤见指南 把免费 Key 接入 Claude Code / Codex / Cline / OpenCode，配置细节以各工具官方文档为准。

免费 AI API 的 Base URL 怎么填？需要加 /chat/completions 吗？

没有统一答案，取决于工具的要求。有的工具要求 Base URL 填到 /v1，工具自己在后面拼 /chat/completions；有的工具要求填完整的请求地址。如果两边都加了 /chat/completions，请求会打到 /chat/completions/chat/completions，返回 404。遇到 404 时先检查是不是路径重复。

只有哔哩哔哩 Index-Translate 的领取步骤明确写了 Base URL（index-translate.bilibili.com/v1，模型名 Index-Translate-35B-A3B），其余额度的 Base URL 与模型 ID 未注明，以厂商官方页面为准。领取第一个 Key 的完整流程见指南 领取第一个免费 Key 并完成第一次调用。

这些免费 API 在中国大陆能用吗？需要翻墙吗？

每条额度都有「国内直连」标注：标注为国内直连的有 18 条（以阿里云、智谱、腾讯、硅基流动等国内厂商为主），其余 25 条国内直连情况未确认。标注反映的是核实当时的判断，不是实时实测结果。

海外厂商的可用性说法不一，需要实测。以 OpenRouter 为例：有来源称「OpenRouter 不受墙限制」，也有来源称「大陆访问需要代理」。两种说法都存在，无法裁决。判断方法：直接打开厂商网站和 API 端点测试，或用一次 curl 调用看是否通；网站能打开不等于 API 能调用，支付环节也可能单独受限。

Claude Code 是免费的吗？免费版 Claude 包含 Claude Code 吗？

工具免费，模型通常不免费。Claude Code 的命令行工具本身可以免费下载安装，但它调用模型要消耗 API 额度或订阅。按社区整理的 Anthropic 说明，免费套餐（Free plan）不包含 Claude Code；要使用它需要付费订阅或 API 额度。领取前请以 Anthropic 官方页为准。

编程类额度是 Qoder、WorkBuddy / CodeBuddy、TRAE、Kiro 学生计划、Dify Cloud，均为各自客户端或云端内的积分/额度，不是 Claude Code 的额度。对比见 免费编程工具额度对比。

遇到 429 怎么办？是等一分钟还是等到明天？

先看报错信息里写的是哪种限速：分钟级（RPM/TPM）等一会儿再试，日级（RPD/TPD）要等到重置时间。有的厂商会在响应头里给 Retry-After（建议等待秒数），以该值为准。不要无脑重试——OpenRouter 的注意事项明确写明「失败请求也计入每日上限」，重试会加速耗尽日额。

日级限速的等待时间取决于各家的重置时间，例如 Cloudflare 在每天 00:00 UTC（北京时间 08:00）重置，华为云码道在每天 24:00（UTC+8）重置，AMD 在北京时间 0 点重置。具体见各额度页的「重置」字段。长期缓解办法：降低并发、用指数退避、把请求分散到多个厂商（不要违反厂商条款）。完整排查见指南 401 / 402 / 429 报错排查。

免费层的数据会被用来训练模型吗？能用于商业用途吗？

各家政策不同，不能一概而论。「注意」事项只在厂商明确说明时标注，例如 Google AI Studio（Gemini API 免费层）的注意事项写明「免费层数据可能被用于改进 Google 产品」。其余额度的数据政策未注明，以厂商官方条款为准。

商业用途同样看各家条款：有的免费层允许商业使用，有的限制为非商业或要求升级。涉及生产用途、客户数据、合规要求时，务必先读厂商的服务条款与数据处理政策，不要凭「免费」两个字假设可以商用。

Are free LLM APIs really free?

是真的免费，但「免费」有四种形态，区别很大（完整对比见 免费额度形态对比）：

  • 长期免费层：不设截止日，按限速免费调用，例如智谱 GLM Flash（官方标注完全免费）。
  • 注册赠金：一次性额度，有有效期，例如 Cerebras 的 $5（30 天过期）、Novita 的 $100（90 天有效，限 Sandbox）。
  • 周期重置：每天/每周/每月重新发放，例如 Groq、OpenRouter、ModelScope 的每日额度。
  • 限时活动：有明确截止日，例如 WorkBuddy 的混元 Hy4 活动（2026-11-15 截止）。

判断「是不是真的免费」要看四点：要不要绑卡、有没有有效期、用完会不会转付费、限速够不够用。每条额度都标明了这四点，领取前请以厂商官方页为准。

OpenRouter 免费模型每天 50 次，充 $10 后真的是 1000 次吗？

按额度原文（核实于 2026-10-27）：「20 RPM / 50 次每天；账户充过 $10 后 1000 次每天」。也就是说，免费模型默认每天 50 次请求，账户充值满 $10 后上限提高到每天 1000 次。OpenRouter 官方 FAQ 也说明了这一规则。

注意事项：「失败请求也计入每日上限」——重试会消耗次数；「免费模型清单会变动」——模型 ID 以 :free 结尾，清单以 OpenRouter 官方页为准。详情见 OpenRouter :free 免费模型额度页。
