三层计费结构

验证平台费：Verify 类服务按成功验证收费（如 Twilio $0.05/次、Vonage $0.06084/次），或零验证费只收通道费（如 Plivo、Bird 无平台费）。通道费：按条或按段计费，另加运营商附加费；长短信按段拆分后计费。运营商附加费：按运营商与号码类型另计，金额见各详情页。失败尝试是否计费因服务而异：Twilio 失败或过期不收基础费，但短信尝试始终计费。见 Verify 计费拆解指南与 Verify 计费对比。

AWS SNS 澄清说明

AWS SNS Free Tier 不含短信，旧称每月 100 条免费无官方依据。见 AWS SNS 澄清说明。

停服与类别说明

华为云短信已于 2025-04-25 停止短信发送服务。互亿无线价格与测试条数以官方页面为准。接码平台是接收验证码的虚拟号服务，与发送验证码的短信 API 不是同一类服务。
