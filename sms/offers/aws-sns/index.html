AWS SNS：Free Tier 不含短信

发布于 2026-11-16 · 更新于 2026-11-16 · 来源：AWS SNS 官方产品页 · 核实于 2026-11-15

澄清说明Free Tier 不含短信不作为免费资源

AWS SNS 官方 Free Tier 列表仅含 100 万次发布、10 万次 HTTPS 投递与 1000 次邮件投递，无短信条目。旧称每月前 100 条美国短信免费仅见二手说法，与 2026-10 的核查冲突，无已核实的短信免费额度。短信按量付费，价格因目的地而异。以下内容为澄清说明，不作为免费资源。核实于 2026-11-15。
