试用模式与限制

新账号为试用模式，仅能向最多 5 个已验证测试号码发消息与打电话（注册号码加 4 个已验证测试号码）。试用短信附加 *[FREE SMS DEMO, TEST MESSAGE]* 字样，充值升级后解除限制；试用额度不能购买虚拟号码。定价总览页与两篇支持文章全文均未写试用金额与有效期，以官方页面为准。

短信与 Verify 单价

SMS API 低至 €0.00735 / $0.00860 每条（美国 LVN）；Messages API 低至 €0.00110 / $0.00129 每条。Verify API €0.05200 / $0.06084 每次成功验证，另加消息与语音费率。

说法并列

  • 美元价差异：Vonage 菲律宾区域站与暂存站的同一总览页显示 SMS API 低至 €0.00735 / $0.00809，生产页为 $0.00860，欧元价相同、美元价不同，差异来自汇率换算时点；单价行以生产页为准。

超限规则与付费档

充值升级解除试用限制；升级后计费细则以官方页面为准。
