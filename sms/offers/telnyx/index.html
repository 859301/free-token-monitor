短信单价

消息定价页 RATES 区有发送方类型选择，短信类为三组：Local 含 10DLC、Toll-Free、Short Code（另有一个 RCS 标签，属 RCS 消息而非短信）。美国（国家 United States，货币 USD）：Local 含 10DLC 发送 $0.004/段加运营商费、接收 $0.004/段；Toll-Free 发送 $0.0055/段加运营商费、接收 $0.0055/段；短码发送 $0.007/段加运营商费、接收 $0.007/段。中国（国家切换为 China 后，发送方类型变为唯一的 Alphanumeric Sender ID）：发送 $0.038/段，MMS 与接收均为 N/A。

MMS 与阶梯降价

MMS 发送 $0.015/段、接收 $0.005/段，均另加运营商费。月超 1 亿段自动阶梯降价。运营商费示例：Verizon 外发 $0.0045/段。

说法并列

  • Verify 定价：页头称 From $0.05 a verification，Delivery cost is inside the rate; no separate messaging line for verify.（递送成本已含在内，验证无单独消息费用行。）费率表 Services 行称 Use Verify API via SMS $0.03 per successful verification + SMS API pricing.（每次成功验证 $0.03 加短信 API 费用。）语音、Flash、WhatsApp 三行同为 $0.03 加对应 API 费用。两处不一致，并列呈现，不裁决。
  • 试用额度：开发者文档（Updated 2026-10-16）称 USD $5 in testing credit is provided.（提供 $5 测试额度。）限 1 个已验证号码、终身 10 次更改、终身 15 次投递尝试、消息限长码仅发已验证号码每天 100 条、Verify 仅短信每天最多 50 次、试用号码 30 天内未升级将被收回、付款方式限信用卡。支持文章（Updated 2026-10-14）称 Telnyx may provide free trial credit from time to time... however at this moment in time there are no promotions that provide free trial credit.（Telnyx 有时会提供免费试用额度，但当前没有提供免费试用额度的促销。）开发者文档新 2 天这一事实可注明，不裁决。支持文章内部亦不一致：同一文章又提到 SIP Trunking 用例 purchased using their free sign-up credit.（用免费注册额度购买。）
