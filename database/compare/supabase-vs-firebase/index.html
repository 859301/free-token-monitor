Supabase vs Firebase

核实于 2026-11-13 · 本页更新于 2026-11-13

Supabase 与 Firebase 都是数据库 + 认证 + 存储 + 函数的全栈免费额度，差异在数据库形态与超限语义：Supabase 是 500 MB 数据库 + 50,000 MAU + 1 GB 文件存储 + Edge Functions 500,000 次，1 周不活跃暂停；Firebase 是 Firestore + Auth + Hosting + Realtime Database 的 No-cost 额度，Spark 超限停用、Blaze 按量且无法设硬上限，Functions 与 Storage 的免费额度在 Blaze 列。

超限语义

Supabase 的约束是暂停：1 周不活跃暂停，至多 2 个活跃项目。Firebase 的约束分计划：Spark 有硬上限，超出任一计划上限应用停用；Blaze 按量付费，免费额度按日计算，无法设置用量硬上限。Firebase 的完整语义见Spark vs Blaze 指南。

托管

Firebase Hosting 的免费额度是 10 GB 存储 + 每天 360 MB 传输，超出 $0.15/GB。10 GB/月是 Realtime Database 下载的等值表述，不是 Hosting 的额度。Supabase 免费档的官网已读页面未述托管额度。

怎么选

需要 Postgres 方向的数据库 + 认证 + 存储 + 函数在同一个免费档里：Supabase。需要 Firestore/Realtime Database + Auth + Hosting 的组合：Firebase，同时分清 Spark 与 Blaze 的语义：Spark 超限停用，Blaze 按量且无法设硬上限，Functions 与 Storage 的免费额度在 Blaze 列。
