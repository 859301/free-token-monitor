自托管 vs 托管数据库

核实于 2026-11-13 · 本页更新于 2026-11-13

托管免费档与自托管是两条路线：托管免费档免运维，但有暂停、休眠、超限规则；自托管在 VPS 上自己部署，没有托管免费档的暂停规则，但有服务器费用与运维成本。有开发者因为国内访问慢，讨论自部署 Supabase 与 PocketBase。

托管免费档

托管免费档免运维：Supabase、Neon、Turso、Upstash Redis、MongoDB Atlas、Firebase 的免费档都不需要自己维护服务器。约束是各家官网的暂停、休眠、超限规则：Supabase 1 周不活跃暂停，Neon 5 分钟闲置 scale to zero，Turso 超限需升级/阻塞，Firebase Spark 超限停用、Blaze 按量且无法设硬上限。

自托管

自托管是在 VPS 上自己部署数据库软件，环境自己装、自己运维。PocketBase 是自托管软件，不是托管免费额度。自托管没有托管免费档的暂停规则，但备份、升级、安全都自己负责。

国内访问延迟

有 V2EX 帖子讨论国内访问慢、自部署 Supabase 与 PocketBase。没有速度实测数据，各家机房位置以官方页面为准。自托管可以把数据库放在自己选的服务器上，延迟取决于服务器位置与网络，以实测为准。
