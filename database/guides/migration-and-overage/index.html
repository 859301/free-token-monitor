免费数据库超额与迁移

核实于 2026-11-13 · 本页更新于 2026-11-13

免费额度超了之后，各家行为不同：Neon 计算暂停至下个周期（不删数据），Turso 需升级或阻塞，Firebase Spark 停用、Blaze 按量且无法设硬上限；Supabase、Upstash、MongoDB Atlas 的超限行为在官网已读页面中未述。处理方式有三种：升级到付费档、迁移到另一家免费档、迁移到自托管。

三种处理

升级到付费档：Supabase Pro $25/月；Neon Launch 按量 $0.106/CU-hour；Turso Developer $4.99/月（年付）起；Upstash Fixed $10/月起；MongoDB Atlas M2 $9/月起；Firebase Blaze 按量。迁移到另一家免费档：对照新一家的额度口径、暂停规则、绑卡要求，见选择指南。迁移到自托管：在 VPS 上自己部署数据库，见自托管 vs 托管指南。有开发者在 Vercel 与 Supabase 相继超出免费额度后，迁移到腾讯云轻量服务器，超额迁移是真实发生的路径。

迁移通用步骤

  1. 导出数据：在原数据库导出一份完整数据，存到自己手里。
  2. 在新一家创建项目或数据库，对照新一家的免费档条款。
  3. 导入数据，核对行数与关键表。
  4. 切换连接：把应用的连接信息改到新数据库，先在测试环境验证读写。
  5. 观察一个用量周期：确认新一家的用量口径、暂停规则、超限行为符合预期，再停用原数据库。

导出与导入的具体命令按各家官方文档操作，以官方页面为准。

自托管迁移路线

自托管是在 VPS 上自己部署数据库，运维自己负责，见自托管 vs 托管指南与免费 VPS 列表。自托管没有托管免费档的暂停规则，但有服务器费用与运维成本。

迁移前对照什么

新一家的额度口径（存储、计算、行读写、命令数各不相同）、暂停与休眠规则、绑卡要求、超限行为、升级价。旧数据的导出格式与新一家的导入要求，以各家官方文档为准。
